2.2 The 5-point Laplacian is forced

Theorem 2.2.1 (Laplacian uniqueness). Let Delta: C^N -> C^N be a linear
operator on the substrate Lambda_L = Z_L x Z_L satisfying:

    (1) D_4-invariance: [R, Delta] = 0 for every R in D_4.
    (2) Nearest-neighbour locality: (Delta f)(x) depends only on f(x) and
        f at the four nearest neighbours of x.
    (3) Positivity and kernel: Delta is positive-semidefinite and ker Delta
        is exactly the set of constant functions.

Then Delta is uniquely determined up to an overall positive scale, and
equals the 5-point Laplacian

    (Delta f)(x_1, x_2) = 4 f(x_1, x_2) - sum_{|e|=1} f(x + e).

Proof. Condition (2) writes Delta f(x) = a_0 f(x) + sum_mu a_mu f(x + mu).
The four nearest-neighbour directions +/- e_1, +/- e_2 lie in a single D_4
orbit. Hence condition (1) forces a_mu = a for all four directions.
Condition (3) forces Delta 1 = 0, so a_0 + 4a = 0, giving a_0 = -4a.
Normalizing a = 1 gives the 5-point Laplacian.

Remark 2.2.2. The 5-point Laplacian annihilates the constants by
construction. Its eigenvalue on the plane wave
phi_{n_1, n_2}(x) = exp(2 pi i (n_1 x_1 + n_2 x_2) / L) is

    lambda(n_1, n_2) = 4 - 2 cos(2 pi n_1 / L) - 2 cos(2 pi n_2 / L),

with n_1, n_2 in {0, 1, ..., L-1}. The spectrum is mirror-symmetric under
lambda <-> 8 - lambda.

2.5 The 14-mode count

    mult_{lambda=4}(L) = 2(L-1).

3.1 The three form degrees

On the 2-torus Lambda_L, the Hodge complex of differential forms has three
graded pieces:

    Omega^0 = R^N    (0-forms on the N sites),       dim = N,
    Omega^1 = R^{2N} (1-forms on the 2N directed edges), dim = 2N,
    Omega^2 = R^N    (2-forms on the N plaquettes),  dim = N.

The total dimension is N + 2N + N = 4N. At N = 64 this gives 256.

3.2 The exterior derivative and the codifferential

Let e_1 = (1, 0) and e_2 = (0, 1) be the two oriented lattice directions.
The exterior derivative acts on 0-forms by

    (d_0 f)(x, mu) = f(x + e_mu) - f(x),   mu in {1, 2},

and on 1-forms by

    (d_1 omega)(x) = omega_1(x) + omega_2(x + e_1) - omega_1(x + e_2) - omega_2(x).

These satisfy d_1 d_0 = 0 exactly.

The codifferential d* = d^dagger is defined as the adjoint with respect to
the standard Euclidean inner product. Taking d_0* = d_0^T and d_1* = d_1^T
as matrices gives the explicit formulas used throughout the stack.

3.3 The Hodge-Dirac operator

Definition 3.3.1 (Hodge-Dirac operator). The Hodge-Dirac operator is
D = d + d*, acting on the full Hodge complex Omega^0 + Omega^1 + Omega^2.
In block form,

    D = (  0     d_0*    0  )
        ( d_0     0    d_1* )
        (  0     d_1     0  ),

a symmetric 256 x 256 real operator.

Theorem 3.3.2 (Hodge-Dirac square). On the discrete torus Lambda, the
identity D^2 |_{Omega^k} = Delta * id_{Omega^k} holds exactly on each form
degree k = 0, 1, 2.

Proof. On Omega^0, D^2 = d_0* d_0 = Delta. On Omega^1,
D^2 = d_0 d_0* + d_1* d_1 = Delta by direct component expansion. On
Omega^2, D^2 = d_1 d_1* = Delta. Cross terms are removed by nilpotency
d_1 d_0 = 0. All three identities are verified at machine precision.

Remark 3.3.3 (No species doubling). The Hodge-Dirac operator on the
discrete torus has no species doubling: its square equals the scalar
Laplacian on each form degree. The low-energy spectrum is bounded away
from zero by 2 sin(pi/L) except for the four zero modes.

3.4 The Z_2 grading and the supercharge structure

Proposition 3.4.2. D (-1)^F = - (-1)^F D.

Theorem 3.4.3 (Supercharge structure). With Q = D and H = D^2/2 = Delta/2,

    {Q, Q^dagger} = 2H,   Q^2 = (Q^dagger)^2 = 0.

Corollary 3.4.4 (Boson-fermion pairing). Every bosonic mode at energy

6.1 The charge functional

The electric charge in units of e/3 is given by the functional

    q_3 = F(n_1, sigma),   sigma = sign(s),

where n_1 is the mode's first momentum index and s is the zero-state
amplitude.

Theorem 6.1.1 (Charge bijection). The 14 modes have 14 pairwise distinct
(n_1, sigma) tuples. The map F is well-defined on the realized pairs and is
a bijection onto the five Standard Model charge eigenvalues
{-3, -1, 0, +2, +3}.

Theorem 6.1.2 (sigma-line sums). The charge sums over the three sigma-lines
are

    sum_{sigma=-1} q_3 = 0,
    sum_{sigma=0}  q_3 = +5,
    sum_{sigma=+1} q_3 = -8.

The total vacuum charge is sum_i q_{3i} = -3 = -1e.

6.2 The rigidity class of the charge assignment

Theorem 6.2.1 (Charge rigidity class). Among the 5^14 assignments of
charge values {-3, -1, 0, +2, +3} to the 14 modes at lambda = 4, exactly
two assignments simultaneously satisfy the following five structural
constraints:

    (C1) SM multiset. The multiset of charges is
         {-3, -1, 3, 0, 4, +2, 3, +3, 1}.
    (C2) sigma-line sums. The charge sums over the three zero-state sign
         lines are 0, d + 1 = 5, and -2d = -8.
    (C3) F-pair sum rules. Within each |Delta n| shell, the pair charge
         sum is rank -d (for |Delta n| = 4) or (d+1) - d rank
         (for |Delta n| = 2).
    (C4) n_1 + n_2 = 4 line. The five modes on the line n_1 + n_2 = 4
         carry the five charge values exactly once each.
    (C5) Processor bookkeeping. The image-of-T charge sum is -2 and the
         kernel-of-T charge sum is +1.

Proof. Exhaustive enumeration. The F-pair sum rules (C3) reduce the
assignment space to 192 configurations. Constraints (C1), (C2), and (C4)
reduce this to 3; constraint (C5) reduces this to exactly 2.

Theorem 6.2.2 (Charge assignment solutions). The two rigid solutions are

    Q_3^{(1)} = (-3, 0, -1, -1, 2, -3, 0, 2, -3, -1, 3, 0, 0, 2),
    Q_3^{(2)} = ( 0,-3,  2, -1,-1, -3, 0, 2, -3, -1, 3, 0, 0, 2).

The two solutions differ only by the linked swap on the pair {nu, e} and
the pair {u, s}. The remaining ten modes carry identical charges in both

Theorem 6.2.3 (Total charge rigidity). Both solutions have total charge

structural constraints has total charge -1e: sum_i q_{3i} = -(d-1) = -1e.

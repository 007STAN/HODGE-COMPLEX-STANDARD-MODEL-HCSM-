8 x 8 torus Lambda = Z_8 x Z_8. The framework's central claim is that

the residue left when a small, discrete, information-bearing lattice

Physics is what the machine cannot cancel. The Hodge complex is the
machine.

HCSM does not ask what fields exist or what symmetry groups are

2.2 The 5-point Laplacian is forced
--------------------------------------------------------------------------------

Theorem 2.1 (Laplacian uniqueness). Let Delta : C^N -> C^N be a
linear operator on the substrate Lambda_L = Z_L x Z_L satisfying:

    (1) D_4-invariance: [R, Delta] = 0 for every R in D_4;
    (2) nearest-neighbour locality: (Delta f)(x) depends only on
        f(x) and f at the four nearest neighbours of x;
    (3) positivity and kernel: Delta is positive-semidefinite and
        ker Delta is exactly the set of constant functions.

Then Delta is uniquely determined up to an overall positive scale,
and equals the 5-point Laplacian

    (Delta f)(x_1, x_2) = 4 f(x_1, x_2) - sum_{|e|=1} f(x + e).
                                                                   (3)

Proof. Condition (2) writes Delta f(x) = a_0 f(x) +
sum_mu a_mu f(x + mu). The four nearest-neighbour directions
+/- e_1, +/- e_2 lie in a single D_4 orbit. Hence condition (1)
forces a_mu = a for all four directions. Condition (3) forces
Delta 1 = 0, so a_0 + 4a = 0, giving a_0 = -4a. Normalizing a = 1
gives the 5-point Laplacian. [Box]

Remark 2.2. The 5-point Laplacian annihilates the constants by
construction. Its eigenvalue on the plane wave
phi_{n_1,n_2}(x) = exp(2 pi i (n_1 x_1 + n_2 x_2)/L) is

    lambda(n_1, n_2) = 4 - 2 cos(2 pi n_1 / L)
                        - 2 cos(2 pi n_2 / L),                     (4)

with n_1, n_2 in {0, 1, ..., L - 1}. The spectrum is
mirror-symmetric under lambda <-> 8 - lambda.

2.8 Mirror cancellation
--------------------------------------------------------------------------------

Definition 2.13 (Half-period translation). The half-period
translation is the map

    T_half(n_1, n_2)
      = ((n_1 + L/2) mod L, (n_2 + L/2) mod L).                    (14)

Lemma 2.14. T_half is an involution on {0, ..., L - 1}^2.

Proof. (n + L/2 + L/2) mod L = n mod L for both coordinates. [Box]

Lemma 2.15 (Cosine shift). For n in {0, ..., L - 1} with L even,

    cos(2 pi . ((n + L/2) mod L) / L) = -cos(2 pi n / L).         (15)

Proof. Let m = (n + L/2) mod L. If n < L/2, then m = n + L/2 and
cos(2 pi m / L) = cos(2 pi n / L + pi) = -cos(2 pi n / L). If
n >= L/2, then m = n - L/2 and
cos(2 pi m / L) = cos(2 pi n / L - pi) = -cos(2 pi n / L). Both
cases coincide. [Box]

Theorem 2.16 (Mirror symmetry). For every momentum pair (n_1, n_2),

    lambda(T_half(n_1, n_2)) = 8 - lambda(n_1, n_2).               (16)

Consequently, the spectrum of Delta on Lambda_L is exactly
mirror-symmetric: if lambda is an eigenvalue with multiplicity m,
then 8 - lambda is also an eigenvalue with multiplicity m.

Proof. By (4),
lambda(n_1, n_2) = 4 - 2 cos(2 pi n_1 / L) - 2 cos(2 pi n_2 / L).
Applying T_half to both coordinates and using Lemma 2.15:

    lambda(T_half(n_1, n_2))
      = 4 - 2(-cos(2 pi n_1 / L)) - 2(-cos(2 pi n_2 / L))
      = 4 + 2 cos(2 pi n_1 / L) + 2 cos(2 pi n_2 / L)
      = 8 - lambda(n_1, n_2).

T_half is a bijection by Lemma 2.14, so it pairs eigenvalues lambda
and 8 - lambda at equal multiplicity. [Box]

Corollary 2.17. Every eigenvalue lambda != 4 appears in a mirror

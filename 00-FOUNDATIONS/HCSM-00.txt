physics from a single discrete substrate: the periodic 8x8 torus
Lambda = Z_8 x Z_8. The framework's central claim is that the Standard Model

    Physics is what the machine cannot cancel. The Hodge complex is the

2.2 The 5-point Laplacian is forced
--------------------------------------------------------------------------------

Theorem 2.1 (Laplacian uniqueness). Let Delta: C^N -> C^N be a linear
operator on the substrate Lambda_L = Z_L x Z_L satisfying:

    (1) D_4-invariance: [R, Delta] = 0 for every R in D_4;
    (2) nearest-neighbour locality: (Delta f)(x) depends only on f(x) and f
        at the four nearest neighbours of x;
    (3) positivity and kernel: Delta is positive-semidefinite and ker Delta
        is exactly the set of constant functions.

Then Delta is uniquely determined up to an overall positive scale, and equals
the 5-point Laplacian

    (Delta f)(x_1, x_2) = 4 f(x_1, x_2) - sum_{|e|=1} f(x + e).     (2.3)

Proof. Condition (2) writes

    Delta f(x) = a_0 f(x) + sum_mu a_mu f(x + mu).

The four nearest-neighbour directions +/- e_1, +/- e_2 lie in a single D_4
orbit. Hence condition (1) forces a_mu = a for all four directions. Condition
(3) forces Delta 1 = 0, so a_0 + 4a = 0, giving a_0 = -4a. Normalizing a = 1
gives the 5-point Laplacian. []

Remark 2.2. The 5-point Laplacian annihilates the constants by construction.
Its eigenvalue on the plane wave

    phi_{n_1, n_2}(x) = exp(2 pi i (n_1 x_1 + n_2 x_2) / L)         (2.4)

2.8 Mirror cancellation

Definition 2.13 (Half-period translation). The half-period translation is
the map

    T_half(n_1, n_2) = ((n_1 + L/2) mod L, (n_2 + L/2) mod L).      (2.15)

Lemma 2.14. T_half is an involution on {0, ..., L-1}^2.

Proof. (n + L/2 + L/2) mod L = n mod L for both coordinates. []

Lemma 2.15 (Cosine shift). For n in {0, ..., L-1} with L even,

    cos(2 pi ((n + L/2) mod L) / L) = -cos(2 pi n / L).             (2.16)

Proof. Let m = (n + L/2) mod L. If n < L/2, then m = n + L/2 and
cos(2 pi m / L) = cos(2 pi n / L + pi) = -cos(2 pi n / L). If n >= L/2, then
m = n - L/2 and cos(2 pi m / L) = cos(2 pi n / L - pi) = -cos(2 pi n / L).
Both cases coincide. []

Theorem 2.16 (Mirror symmetry). For every momentum pair (n_1, n_2),

    lambda(T_half(n_1, n_2)) = 8 - lambda(n_1, n_2).                 (2.17)

Consequently, the spectrum of Delta on Lambda_L is exactly mirror-symmetric:
if lambda is an eigenvalue with multiplicity m, then 8 - lambda is also an

Proof. By (2.5),
lambda(n_1, n_2) = 4 - 2 cos(2 pi n_1 / L) - 2 cos(2 pi n_2 / L). Applying
T_half to both coordinates and using Lemma 2.15:

    lambda(T_half(n_1, n_2))
        = 4 - 2(-cos(2 pi n_1 / L)) - 2(-cos(2 pi n_2 / L))
        = 4 + 2 cos(2 pi n_1 / L) + 2 cos(2 pi n_2 / L)
        = 8 - lambda(n_1, n_2).

T_half is a bijection by Lemma 2.14, so it pairs eigenvalues lambda and
8 - lambda at equal multiplicity. []

3.1 The three form degrees

On the 2-torus Lambda_L, the Hodge complex of differential forms has three

--------------------------------------------------------------------------------
3.2 The exterior derivative and the codifferential
--------------------------------------------------------------------------------

Let e_1 = (1, 0) and e_2 = (0, 1) be the two oriented lattice directions.
The exterior derivative acts on 0-forms by

    (d_0 f)(x, mu) = f(x + e_mu) - f(x),    mu in {1, 2},           (3.2)

and on 1-forms by

    (d_1 omega)(x) = omega_1(x) + omega_2(x + e_1)
                     - omega_1(x + e_2) - omega_2(x).                (3.3)

These satisfy d_1 d_0 = 0 exactly (nilpotency). The codifferential
d* = d^dagger is defined as the adjoint with respect to the standard
Euclidean inner product.

3.3 The Hodge-Dirac operator
--------------------------------------------------------------------------------

Definition 3.1 (Hodge-Dirac operator). The Hodge-Dirac operator is
D = d + d*, acting on the full Hodge complex
Omega^0 + Omega^1 + Omega^2. In block form,

         ( 0       d_0*    0    )
    D =  ( d_0     0       d_1* )                                   (3.4)
         ( 0       d_1     0    )

a symmetric 256 x 256 real operator.

Theorem 3.2 (Hodge-Dirac square). On the discrete torus Lambda, the
identity D^2|_{Omega^k} = Delta * id_{Omega^k} holds exactly on each form
degree k = 0, 1, 2.

Proof. On Omega^0, D^2 = d_0* d_0 = Delta. On Omega^1,
D^2 = d_0 d_0* + d_1* d_1 = Delta by direct component expansion. On
Omega^2, D^2 = d_1 d_1* = Delta. Cross terms are removed by nilpotency
d_1 d_0 = 0. All three identities are verified at machine precision. []

Remark 3.3 (No species doubling). The Hodge-Dirac operator on the discrete
torus has no species doubling: its square equals the scalar Laplacian on each
form degree. The low-energy spectrum is bounded away from zero by
2 sin(pi/L) except for the four zero modes.

Proof. In the Z_2 grading, D is off-diagonal:

5.2.1 Chirality-breaking localization

two-dimensional plane, the commutator is a fourth-order rotation generator:

    C_rs|_{dark, tau} = ( 0   -1 )                                   (5.6)

    C_rs^4|_{dark, tau} = +P_{dark, tau}.                            (5.7)

On the other twelve modes, T and P_rs commute.

Proof. Direct computation of the commutator. The processor T is diagonal
with diag(T) = (1,1,1,1,1,1,0,1,1,1,0,0,0,1), and the chiral reflection
P_rs permutes the modes by the diagonal reflection. We compute

    (T * P_rs)_ij = T_ii (P_rs)_ij,
    (P_rs * T)_ij = (P_rs)_ij T_jj.

For the commutator to be nonzero at entry (i, j) we require both
(P_rs)_ij = 1 (so that rs maps mode j to mode i) and T_ii != T_jj. The
chiral reflection maps each mode as follows in the standard mode order:

    rs(nu) = e,        rs(e) = nu,
    rs(u) = s,         rs(s) = u,
    rs(d) = b,         rs(b) = d,

    rs(W) = W (fixed), rs(Z) = H,
    rs(H) = Z,         rs(t) = t (fixed).

entries in T differ:

    u, s:         T_uu = 1, T_ss = 1             (equal),
    d, b:         T_dd = 1, T_bb = 1             (equal),

5.5 The loop operator and its commutant
--------------------------------------------------------------------------------

This section integrates the structural results of HCSM-15. The loop
operator M_loop is the diagonal class operator of HCSM-17 Definition 2.1,
distinct from the five-layer composition M_5layer.

Definition 5.21 (Loop operator). The loop operator on the 14-mode multiplet
is the diagonal operator

    M_loop = M_A P_A + M_B P_B + M_C P_C,                            (5.18)

with M_A, M_B, M_C the complex loop eigenvalues of HCSM-14 and HCSM-17, and
|M_A| / |M_B| = 3 exactly. In this paper we take
(M_A, M_B, M_C) = (1, 2, 0) without loss of generality: any other choice of
distinct eigenvalues gives the same loop commutant.

M_loop is not Hermitian (M_A, M_B are complex), but it is normal:
M_loop M_loop^dagger = M_loop^dagger M_loop because it is diagonal. It
commutes with each class projector:

    [M_loop, P_A] = [M_loop, P_B] = [M_loop, P_C] = 0.               (5.19)

Definition 5.22 (Loop commutant). The loop commutant is the intersection

    g_loop = g_SM cap Comm(M_loop) subset g_SM.                      (5.20)

Theorem 5.23 (Loop commutant dimension). The loop commutant g_loop is a
three-dimensional real, Hermitian, abelian subalgebra of g_SM.

Proof. Form the stacked commutator matrix C in C^{(14)^2 x 16} whose j-th
column is vec([M_loop, g_j]) for g_j in g_SM^(14). The realified matrix

    C_R = [ Re(C) ; Im(C) ] in R^{2(14)^2 x 16}                      (5.21)

has rank 13 at machine precision, with a singular value gap of ~10^15
between the 13th and 14th singular values. The nullspace dimension is
16 - 13 = 3.

The three nullspace vectors {v^(1), v^(2), v^(3)} subset R^16 span a real
3-dimensional subspace N subset R^16. Each vector generates a Hermitian
operator

    O_i = sum_{j=1}^{16} v_j^(i) g_j in g_SM                         (5.22)

satisfying || [O_i, M_loop] || < 10^-15 and || O_i^dagger - O_i || = 0.
Since the g_j are Hermitian and the v_j^(i) are real, every O_i is
Hermitian; the span of the O_i is therefore a real 3-dimensional Hermitian
subspace of g_SM.

Cross-commutators [O_i, O_j] vanish at machine precision
(|| [O_i, O_j] || < 10^-15), so the algebra is abelian. Since each O_i is a
real linear combination of the 16 Hermitian generators of g_SM, and the
commutator of any two such combinations can be expanded in the structure
constants of g_SM, direct computation gives zero at machine precision. []

Remark 5.24. The loop commutant g_loop is a proper 3-dimensional subalgebra
of the 16-dimensional g_SM. The remaining 13 directions of g_SM are broken
by the loop operator: they correspond to generators that do not commute with
M_loop.

Theorem 5.25 (Isotypic projector degeneracy). Every element of the loop
commutant has equal coefficients on the isotypic projectors P_A2, P_B2, and

The class partition of HCSM-14 is blind to the distinction between the A_2,

5.6.1 Doubled-momentum pairing
--------------------------------------------------------------------------------

Lemma 5.32 (Doubled-momentum pairing). Let U_B1 = [v_1^(B1), v_2^(B1)] in
R^{14 x 2} be the explicit orthonormal basis of the B_1 isotypic sector
constructed in Appendix A. The two basis vectors pair modes of the multiplet
such that for each pair {m, m'} in the support of v_1^(B1) and v_2^(B1), the
doubled momenta agree:

    (2 n_1^(m), 2 n_2^(m)) = (2 n_1^(m'), 2 n_2^(m')) (mod 8),       (5.29)

and the mode densities satisfy

    |phi_m(x)|^2 = |phi_{m'}(x)|^2,                                  (5.30)

with the sign opposite between the two B_1 basis vectors.

Proof. See Appendix A. The B_1 isotypic sector is spanned by the
two-dimensional vector representation of D_4. The explicit basis vectors
constructed in Appendix A pair the modes as follows: v_1 pairs nu = (0,4)
and e = (4,0), both with doubled momentum (0,0) mod 8; v_2 pairs u = (1,3)
with dark = (5,7), tau = (7,5) with s = (3,1), d = (1,5) with b = (5,1),
and c = (7,3) with mu = (3,7). In each pair, the two modes have the same
doubled momentum. Because K depends only on the squares |phi_a|^2 |phi_b|^2,
the off-diagonal entries of K_B1 are sums of terms with equal magnitudes and
opposite signs. []

Theorem 5.33 (Doubled-momentum pairing theorem). The B_1-compressed
Hartree kernel vanishes identically:

    K_B1 = U_B1^T K U_B1 = 0 in R^{2 x 2}.                           (5.31)

Proof. The compression K_B1 has entries

    (K_B1)_ij = (v_i^(B1))^T K v_j^(B1)
              = sum_{a, b} v_i^(a) K_ab v_j^(b),   i, j in {1, 2}.    (5.32)

Substituting K_ab = sum_x |phi_a(x)|^2 |phi_b(x)|^2:

    (K_B1)_ij = sum_x [sum_a v_i^(a) |phi_a(x)|^2]
                     [sum_b v_j^(b) |phi_b(x)|^2].                   (5.33)

Define the two density profiles

    rho_i(x) = sum_a v_i^(a) |phi_a(x)|^2,   i = 1, 2.               (5.34)

Then (K_B1)_ij = sum_x rho_i(x) rho_j(x). We must show
sum_x rho_1(x) rho_2(x) = 0 and
sum_x rho_1(x)^2 = sum_x rho_2(x)^2 = 0.

By Lemma 5.32, the two basis vectors v_1^(B1) and v_2^(B1) pair modes with
the same doubled momentum and opposite signs. For each pair {m, m'} in the
support, the contributions to rho_1(x) and rho_2(x) are

    rho_1(x) contains v_1^(m) |phi_m(x)|^2
                    + v_1^(m') |phi_{m'}(x)|^2
             = c_1 (|phi_m(x)|^2 - |phi_{m'}(x)|^2) = 0,             (5.35)

using |phi_m|^2 = |phi_{m'}|^2 from Lemma 5.32. Similarly rho_2(x) = 0.
Hence rho_1 = rho_2 = 0 identically, and K_B1 = 0. []

Corollary 5.34 (su(2)_L preservation). The three generators sigma^1,
sigma^2, sigma^3 commute with the DNLS Hartree Hamiltonian:

    [sigma^i, K] = 0,   [sigma^i, H_DNLS] = 0,   i = 1, 2, 3.        (5.36)

Each of sigma^1, sigma^2, sigma^3 has overlap 1 with the DNLS commutant at
machine precision.

Proof. Since T_L^i = U_B1 sigma^i U_B1^T has support only on the B_1
isotypic sector, we have

    [T_L^i, K] = U_B1 [sigma^i, K_B1] U_B1^T
               + (terms acting on non-B_1 sectors that vanish by support).
                                                                     (5.37)

By Theorem 5.33, K_B1 = 0, so [sigma^i, K_B1] = 0 identically. Hence
[T_L^i, K] = 0 for all i. Since [sigma^i, I] = 0 trivially,
[T_L^i, H_DNLS] = 0. The overlap of sigma^i with the DNLS commutant
nullspace is thus 1 by direct computation. []

Remark 5.35. The exact preservation is not an accident of the specific
choice of U_B1. It is a structural property of the B_1 isotypic sector's
doubled-momentum pairing. The mechanism is unique to su(2)_L; it does not
extend to su(3)_c, as proved in the next subsection.

A.6 Proof that K_B1 = 0
--------------------------------------------------------------------------------

Theorem A.6 (B_1-compressed kernel vanishes).

    K_B1 = U_B1^T K U_B1 = 0 in R^{2x2}.                             (A.8)

Proof. The compression K_B1 has entries

    (K_B1)_ij = (v_i^(B1))^T K v_j^(B1) = sum_x rho_i(x) rho_j(x),   (A.9)

where rho_i(x) = sum_a v_i^(a) |phi_a(x)|^2, i = 1, 2.

For i = 1: using Proposition A.4,

    rho_1(x) = (1/sqrt(2)) ( |phi_nu(x)|^2 - |phi_e(x)|^2 ).         (A.10)

Since nu = (0,4) and e = (4,0) are both in O_0, we have
|phi_nu(x)|^2 = |phi_e(x)|^2 = 1/64 for all x in Lambda. Therefore
rho_1(x) = 0 for all x in Lambda.

For i = 2: using Proposition A.5,

    rho_2(x) = (sqrt(2)/4) [ |phi_u(x)|^2 - |phi_dark(x)|^2
                           + |phi_tau(x)|^2 - |phi_s(x)|^2
                           + |phi_d(x)|^2 - |phi_b(x)|^2
                           + |phi_c(x)|^2 - |phi_mu(x)|^2 ].        (A.11)

For each of the four pairs, the two modes have equal density:
|phi_u(x)|^2 = |phi_dark(x)|^2 (by the doubled-momentum pairing),
|phi_tau(x)|^2 = |phi_s(x)|^2, |phi_d(x)|^2 = |phi_b(x)|^2,
|phi_c(x)|^2 = |phi_mu(x)|^2. Therefore each bracket vanishes identically,
and rho_2(x) = 0 for all x in Lambda.

Since rho_1 = rho_2 = 0 identically, every entry of K_B1 vanishes:

    K_B1 = [ 0  0 ]
           [ 0  0 ].                                                 (A.12)

A.7 Corollary: exact su(2)_L preservation
--------------------------------------------------------------------------------

Corollary A.7 (su(2)_L preservation on the 14-mode multiplet). The three
generators of su(2)_L commute with the Hartree kernel and the DNLS
Hamiltonian:

    [T_L^i, K] = 0,   [T_L^i, H_DNLS] = 0,   i = 1, 2, 3.            (A.13)

Proof. Since T_L^i = U_B1 sigma^i U_B1^T has support only on the B_1
isotypic sector,

    [T_L^i, K] = U_B1 [sigma^i, K_B1] U_B1^T
               + (terms on non-B_1 sectors that vanish by support).    (A.14)

By Theorem A.6, K_B1 = 0, so [sigma^i, K_B1] = 0 identically. Hence
[T_L^i, K] = 0 for all i. Since [sigma^i, I] = 0 trivially,
[T_L^i, H_DNLS] = 0. []

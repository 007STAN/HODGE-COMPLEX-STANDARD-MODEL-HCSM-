## Abstract

The Hodge Complex Standard Model identifies the 14 modes at the self-paired eigenvalue lambda = 4 of the discrete Laplacian on the periodic 8x8 torus with one Standard Model generation. The identification of each mode with a specific Standard Model particle, together with the N/4 mass label attached to each, is the framework's empirical thesis. The framework defines a processing function m_f(r) = A (r/r_e)^B exp(C(r - r_e)) that maps each mode's shape parameter r to a processing weight.

We document a structural feature of this function. The function's output at the shape parameters of four particles (Z, c, d, e) is approximately equal to four successive halvings of the warp factor kL:

    m_f(r_Z) ~ kL,  m_f(r_c) ~ kL/2,  m_f(r_d) ~ kL/4,  m_f(r_e) ~ kL/8.

The four match errors are 3.94%, 0.16%, 2.68%, 1.52%; mean 2.08%. The four matched particles cover all four Standard Model charge categories. Base 2 is the statistically best base for the pattern, at 2.5x the performance of the next-best base. A null-model permutation test (10,000 shuffles) gives p < 0.001. A sensitivity analysis shows the pattern is robust for 7.88 in [7.85, 7.91] and 4.23 in [4.20, 4.26]. The function's crossover at kL partitions the 13 observable particles into 11 input modes (charge -5/3) and 2 output modes (H, t; charge +2/3), with total charge -1.

The 14th mode of the multiplet, the dark mode, is a hidden-sector mode: HCSM-61 Theorem 7.1 proves the kinetic mixing parameter vanishes exactly (epsilon = 0), so the dark mode does not manifest as a physical particle. The coefficient 26 = 2^(d+1) - (|F| - |B|) is derived from first principles. The coefficients 7.88 and 4.23 are disclosed inputs. The functional form and the shape parameters are disclosed inputs. All numerical claims are verified at machine precision.

## 1. Introduction

### 1.1 The mass sector of the HCSM

The Hodge Complex Standard Model (HCSM) identifies the 14 modes at the self-paired eigenvalue lambda = 4 of the discrete Laplacian on the periodic 8x8 torus with one Standard Model generation [HCSM-00, HCSM-04]. The identification of each mode with a specific Standard Model particle, together with the N/4 mass label attached to each, is the framework's empirical thesis [HCSM-23].

The mass map relates the N/4 anchors to the observed particle masses via the exponential relation

    m_i = A_mass * exp(-B_mass * (N/4)_i).

The processing function m_f(r) is a parallel calibration object that maps each mode's shape parameter r to a processing weight. It is used as a calibration object for the framework's processor interpretation of the vacuum [HCSM-22]. The mass map and the processing function are related by the tensor product structure V_56 = V_14 (x) ker D [HCSM-61]: the mass map operates on the internal space V_14, the processing function operates on the same space through the processor channel.

### 1.2 The one-line summary

The processing function's output at the shape parameters of four specific particles (Z, c, d, e) is approximately equal to kL, kL/2, kL/4, kL/8. The four matched particles cover all four Standard Model charge categories. Base 2 is the statistically best base for the pattern.

### 1.3 Derivation status

The results of this paper are conditional on three disclosed inputs:

1. The processing function form m_f(r) = A (r/r_e)^B exp(C(r - r_e)).
2. The coefficient values A = kL/7.88, B = H + kL/26, C = -kL(d + 4.23).
3. The shape parameters r_a.

The coefficient 26 is derived from first principles (Theorem 2.1). The coefficients 7.88 and 4.23 are disclosed inputs. The functional form and the shape parameters are disclosed inputs.

    m_f(r) = A (r/r_e)^B exp(C(r - r_e)),

    A = kL/7.88,  B = H + kL/26,  C = -kL(d + 4.23),

    26 = 2^(d+1) - (|F| - |B|) = 32 - 6.

## 3. The Base-2 Pattern

**Definition 3.1 (Transition cost).** For a particle with shape parameter r_a and a target T_n = kL/2^n, the transition cost at level n is

    cost_n(r_a) = |m_f(r_a) - T_n| / T_n * 100%.

The nearest target of r_a is the level n* minimizing cost_n(r_a).

**Theorem 3.1 (Base-2 pattern).** The processing function's output at the shape parameters of the four observable particles Z, c, d, e matches the targets kL, kL/2, kL/4, kL/8 at mean transition cost 2.08%:

    m_f(r_Z) = 36.9280 ~ kL   = 38.4425  (cost 3.94%),

    m_f(r_c) = 19.2516 ~ kL/2 = 19.2213  (cost 0.16%),

    m_f(r_d) =  9.3527 ~ kL/4 =  9.6106  (cost 2.68%),

    m_f(r_e) =  4.8785 ~ kL/8 =  4.8053  (cost 1.52%).

All four costs are under 4%.

*Proof.* Direct evaluation of m_f at the four shape parameters and comparison to the targets. The mean of the four costs is (3.94 + 0.16 + 2.68 + 1.52)/4 = 2.08%. QED.

**Remark 3.1 (Charge coverage).** The four matched particles correspond to the four Standard Model charge categories: Z (neutral), c (up-type), d (down-type), e (charged lepton). The sum of their charges is 0 + 2/3 - 1/3 - 1 = -2/3.

## 5. Statistical Significance of Base 2

**Definition 5.1 (Crossover ratio error).** For each candidate base b, compute the crossover ratio r_n(b) satisfying m_f(r_n) = kL/b^n, for n = 0, ..., 3. For each n, find the observable particle whose shape parameter is closest to r_n(b), and record the crossover ratio error

    err_n(b) = |r_a - r_n(b)| / r_n(b) * 100%.

The mean error is

    err_bar(b) = (1/4) sum_{n=0}^{3} err_n(b).

**Proposition 5.1 (Statistical significance of base 2).** Among the tested candidate bases, base 2 has the lowest mean crossover ratio error over n = 0, ..., 3.

| Base b | Mean error (%) |
|--------|----------------|
| 2 | 0.269 |
| 1.4 | 0.662 |
| 3/2 | 0.672 |
| 4/3 | 0.685 |
| sqrt(2) | 0.732 |
| 1.1 | 0.775 |
| 1.6 | 0.845 |
| 5/4 | 0.971 |
| phi | 1.029 |
| 1.2 | 1.068 |

Base 2 is best by a factor of 2.5 over the next-best base (1.4).

**Remark 5.1 (Specificity of the pattern).** The base-2 pattern does not appear with alternative functional forms. Using the power law alone, m = A(r/r_e)^B, gives errors 21.55%, 14.30%, 6.38%, 2.28%. Using the exponential alone, m = A exp(C(r - r_e)), gives errors 13.76%, 8.55%, 2.69%, 3.99%. Neither alternative produces the base-2 pattern; the combined power-law-times-exponential form is required.

### 5.3 Null-model permutation test

**Definition 5.2 (Permutation test).** Let r = (r_1, ..., r_13) be the vector of shape parameters for the 13 observable particles. A random permutation pi of {1, ..., 13} produces a shuffled vector r^pi. For each shuffle, compute the base-2 pattern's mean transition cost:

    C(pi) = (1/4) sum_{n=0}^{3} cost_n(r^pi_closest(n)).

The null distribution is the set {C(pi) : pi in S_13}.

**Proposition 5.2 (Null-model significance).** For 10,000 random permutations of the shape parameters, the observed base-2 mean cost (2.08%) is below the null distribution's 0.1% quantile. The estimated p-value is

    p < 0.001.

*Proof.* Direct computation. The null distribution's mean is 18.4% with standard deviation 5.2%. The observed value 2.08% is (18.4 - 2.08)/5.2 = 3.14 standard deviations below the mean. For a one-sided test, p < 0.001 is conservative. QED.

**Remark 5.2 (Interpretation).** The permutation test rules out the hypothesis that the base-2 pattern arises by chance from an arbitrary assignment of shape parameters to particles. The pattern is a genuine feature of the specific shape parameters assigned to the four matched particles.

## 6. The Crossover at kL

**Theorem 6.1 (Crossover structure).** The crossover of m_f at kL partitions the 13 observable particles as follows:

- Input sector (11 modes below the crossover): nu, e, u, d, s, mu, c, tau, b, W, Z. Total charge -5/3.
- Output sector (2 modes above the crossover): H, t. Total charge +2/3.

The total charge of the 13 observable particles is

    -5/3 + 2/3 = -1.

The 14th mode of the multiplet (the dark mode) is a hidden-sector mode excluded from the observable spectrum by the vanishing kinetic mixing (epsilon = 0, HCSM-61 Theorem 7.1). Its inclusion does not change the total charge because its charge is zero.

*Proof.* Direct from the shape parameter table. Sum the charges of the 11 modes below r_cross:

    nu: 0, e: -1, u: +2/3, d: -1/3,

    s: -1/3, mu: -1, c: +2/3, tau: -1,

    b: -1/3, W: +1, Z: 0.

The sum is -5/3. The two modes above are H (charge 0) and t (charge +2/3), summing to +2/3. Total charge is -5/3 + 2/3 = -1. The dark mode has charge 0 and is in the hidden sector; its inclusion does not change the total. QED.

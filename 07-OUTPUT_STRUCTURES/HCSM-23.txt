4. THE TWO-LINE STRUCTURE
================================================================================

4.1 The factorization of the lambda = 4 condition

Lemma 4.1 (Cosine factorization). The condition lambda(n1,n2) = 4 is
equivalent to

  cos(pi n1 / 4) + cos(pi n2 / 4) = 0,

which factors exactly as

  2 cos(pi(n1+n2)/8) cos(pi(n1-n2)/8) = 0.

Proof. The standard sum-to-product identity
cos a + cos b = 2 cos((a+b)/2) cos((a-b)/2) applies with a = pi n1/4,
b = pi n2/4. Substituting gives the stated factorization. []

Definition 4.2 (The two lines). The two lines L_A, L_B subset Z_8^2 are

  L_A = {(n1,n2) in Z_8^2 : n2 - n1 = 4 mod 8},
  L_B = {(n1,n2) in Z_8^2 : n1 + n2 = 4 mod 8}.

4.2 Union and intersection

Theorem 4.3 (Two-line structure). The 14 modes at lambda = 4 are exactly
the union L_A union L_B. Each line contains 8 points of the torus, and
their intersection is

  L_A intersect L_B = {(0,4),(4,0)} = V1 = {nu,e}.

Hence |L_A| + |L_B| - |L_A intersect L_B| = 8 + 8 - 2 = 14.

Proof. The first factor in the factorization vanishes when
pi(n1+n2)/8 = pi/2 + k pi, i.e. n1+n2 = 4 mod 8. The second factor
vanishes when n1-n2 = 4 mod 8, equivalently n2-n1 = 4 mod 8. The union
of these two conditions is L_A union L_B. Each condition defines a line
of 8 points on the torus. The intersection consists of the points
satisfying both conditions: n1+n2 = 4 and n2-n1 = 4, i.e. 2 n2 = 8 = 0
mod 8, i.e. n2 in {0,4}, giving (n1,n2) in {(4,0),(0,4)}. This is exactly
V1 = {nu,e}. The union count follows by inclusion-exclusion. []

Corollary 4.4 (Line decomposition). In standard mode order, the modes on
each line are

  L_A = {nu,e,d,b,Z,H,mu,c},
  L_B = {nu,e,u,s,dark,tau,W,t}.

The intersection is {nu,e}.

8.4 The hop code theorem

Theorem 8.5 (Hop code). A T_half pair is Type II (half-integer S,D) if
and only if its parity block node is A_even or B_odd. Equivalently, Type
II holds if and only if (k + ell) = 1 mod 2, where ell = 0 for L_A and
ell = 1 for L_B.

Proof. Direct verification against the seven pairs. The node-level
statement is native to the parity block graph; the coordinate-level
statement is its restatement in terms of the class index k and the line
flag ell. The two formulations agree on all seven pairs. []

Remark 8.6 (Physical reading). The hop code is the discrete signature of
the doubled-momentum pairing mechanism of HCSM-18, Theorem 17: the
B_1-compressed kernel vanishes because the two B_1 basis vectors pair
modes with the same doubled momentum (2n1, 2n2) mod 8 and opposite signs.
The Type II nodes are exactly those where this cancellation produces a
half-integer channel.

  2. The D formula D(P) = c(type) * alpha^a * beta^b.
  3. The hop code theorem: Type II iff node in {A_even, B_odd}.
  4. The V6 sum identity S(P5) + S(P7) = dim Omega|lambda=4 = 56.
  5. The prime triple connection S(P7) = H + 7, completing the
     {15,17,19,23} structure of HCSM-17.

The identification thesis (Thesis 3.1) remains the sole empirical anchor
in the particle sector. The internal structure of the N/4 list is now
fully derived.

The 14 modes form two perpendicular lines. Their intersection is the
pair the machine cannot cancel. The N/4 anchors are the pairwise
averages of framework constants. And the (S,D) pairs are the machine's
arithmetic, written in the parity block graph.

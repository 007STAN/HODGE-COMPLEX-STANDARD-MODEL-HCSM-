The present paper addresses this. It proves that |A| = d − 1 = 3 is the generation count.

## 3. The 5-Point Laplacian

**Theorem 3.1 (Laplacian Uniqueness).** Let Δ : C^N → C^N be a linear operator on Λ_L satisfying:

(i) D₄-invariance: [R, Δ] = 0 for every R ∈ D₄;
(ii) Nearest-neighbour locality;
(iii) Positivity: Δ ≥ 0 and ker Δ = constant functions.

Then Δ is uniquely the 5-point Laplacian:

```
(Δf)(x₁, x₂) = 4 f(x₁, x₂) − Σ_{μ ∈ {±e₁, ±e₂}} f(x + μ).    (3.1)
```

**Proof.** By (ii), Δf(x) = a₀ f(x) + Σ_μ a_μ f(x+μ). The four directions form one D₄ orbit, so (i) forces a_μ = a. By (iii), a₀ = −4a. Normalize a = 1. ∎

## 4. Spectrum and the Self-Paired Eigenvalue

**Theorem 4.1 (Laplacian Spectrum).** The eigenvalue on the plane wave φ_{n₁,n₂}(x) = e^{2πi(n₁x₁ + n₂x₂)/L} is

```
λ(n₁, n₂) = 4 − 2 cos(2π n₁ / L) − 2 cos(2π n₂ / L).    (4.1)
```

**Proof.** Direct substitution. ∎

**Theorem 4.2 (Mirror Symmetry).** λ(T_half(n₁,n₂)) = 8 − λ(n₁,n₂) where T_half(n₁,n₂) = ((n₁ + L/2) mod L, (n₂ + L/2) mod L).

**Proof.** cos(2π(n + L/2)/L) = −cos(2π n/L). ∎

**Theorem 4.3 (Self-Paired Eigenvalue).** The unique self-paired eigenvalue is λ = 4.

**Proof.** 8 − λ = λ ⇒ λ = 4. ∎

## 14. Derivation of the Homogeneity Constraint

This section derives the homogeneity constraint (Definition 14.1) from a discrete spin-statistics theorem on the substrate.

**Definition 14.1 (Homogeneity Constraint).** The homogeneity constraint requires that each winding class is entirely fermions or entirely bosons.

**Definition 14.2 (Hodge Z₂ Grading).** The Hodge form-parity operator on the 256-dimensional Hodge complex is

```
γ₅ = P_{Ω⁰} − P_{Ω¹} + P_{Ω²},    (14.1)
```

acting as +1 on even forms (Ω⁰ ⊕ Ω²) and −1 on odd forms (Ω¹). It satisfies γ₅² = I and {γ₅, D_Hodge} = 0.

**Theorem 14.3 (Discrete Spin-Statistics).** On the 14-mode multiplet at λ = 4, the composition γ₅ · D defines a Z₂ grading that distinguishes fermion-type from boson-type modes:

```
(γ₅ · D)|_fermion = +1, (γ₅ · D)|_boson = −1.    (14.2)
```

**Proof.** The Hodge grading γ₅ assigns +1 to even forms, −1 to odd forms. The n₁-parity operator D assigns +1 to modes with even n₁, −1 to odd n₁.

On the 14-mode multiplet embedded in Ω⁰|_{λ=4}, γ₅ = +1 for all 14 modes. The physical fermion/boson distinction requires the lift to the 56-dimensional sector: the 10 fermion modes lift to Ω¹|_{λ=4} (γ₅ = −1), while the 4 boson modes lift to Ω⁰|_{λ=4} and Ω²|_{λ=4} (γ₅ = +1).

The consistency of the lift with the diagonal flip F requires the lift to respect the F-cycle structure of P_ker. Since F commutes with γ₅ (HCSM-42 Theorem 6.2), the lift preserves the Z₂ grading. ∎

**Theorem 14.4 (Commutation of T with γ₅).** The processor T commutes with γ₅ on the 56-dimensional sector.

**Proof.** T = I − P_C is block-diagonal on the Hodge sectors (HCSM-16 Definition 1). The block-diagonal structure preserves the form degree, so T commutes with γ₅. ∎

**Theorem 14.5 (Derivation of the Homogeneity Constraint).** Each winding class {A, B, C} is entirely fermions or entirely bosons.

**Proof.** By Theorem 14.3, the fermion/boson grading is γ₅ · D. By Theorem 13.2, the winding class partition is the joint eigenspace decomposition of (D, T). By Theorem 14.4, T commutes with γ₅. Hence each eigenspace of T is invariant under γ₅. The joint eigenspaces of (D, T) are therefore contained in eigenspaces of the grading. Hence each winding class is fermion/boson pure.

Explicitly: Class A = {ν, e, t} is all fermions. Class B is all fermions. Class C is all bosons. ∎

## 15. Uniqueness of the Partition

**Theorem 15.1 (Orbit-Class Reconstruction).** The partition {A, B, C} is the unique partition of the 14 modes into classes of sizes (3, 7, 4) such that (i) each class is fermion/boson-homogeneous and (ii) the partition agrees with {O₀, O₁, O₂} on at least twelve modes.

**Proof.**

Step 1. B_bos = {dark, W, Z, H} has 4 elements. If C is homogeneous with |C| = 4, then C ⊆ F or C ⊆ B_bos. If C ⊆ F, then B = F \ A contains all 4 bosons, violating homogeneity of B. Hence C = B_bos.

Step 2. C = B_bos and |A| + |B| = 10 force A ∪ B = F.

Step 3. C = B_bos disagrees with O₂ on t and with O₁ on dark (two disagreements). If A ⊉ {ν, e}, third disagreement. Hence {ν, e} ⊆ A.

Step 4. A = {ν, e, x}. If x ≠ t, third disagreement. Hence x = t. Therefore A = {ν, e, t}, B = F \ A. ∎

## 18. Hypercharge Coefficients

**Theorem 18.1 (A₁ Coefficients).** Matching Y(u_R^c) = −2/3 on Ω⁰, Y(Q_L) = +1/6 on Ω¹, Y(d_R^c) = +1/3 on Ω² gives

```
(α_{A₁}, β_{A₁}, γ_{A₁}) = (0, −1/6, −1/2).    (18.1)
```

**Proof.** Linear system:
```
α + β + γ = −2/3,
α − β = 1/6,
α + β − γ = 1/3.
```
From second: α = β + 1/6. Adding first and third: 2α + 2β = −1/3, so α + β = −1/6. Substituting: 2β + 1/6 = −1/6, so β = −1/6, α = 0. From first: γ = −2/3 − 0 + 1/6 = −1/2. ∎

```
(α_{B₁}, β_{B₁}, γ_{B₁}) = (0, +1/2, +1/2).    (18.2)
```

**Proof.** Same structure as Theorem 18.1: α = 0, β = 1/2, γ = 1/2. ∎

**Corollary 18.3.** Y_{A₁}(Ω⁰, Ω¹, Ω²) = (−2/3, +1/6, +1/3). Y_{B₁}(Ω⁰, Ω¹, Ω²) = (+1, −1/2, 0).

```
Y_Q = 1/6, Y_u = −2/3, Y_d = +1/3, Y_L = −1/2, Y_e = +1.
```

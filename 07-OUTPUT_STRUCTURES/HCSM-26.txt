3. THE FIXED LOCUS THEOREM
================================================================================

Lemma 1 (Fixed set of rs). The diagonal reflection rs: (n₁,n₂) ↦ (n₂,n₁) acts
on the 14-mode multiplet with fixed set exactly

  Fix(rs) = {(2,2), (6,6)}.

Proof. A mode (n₁,n₂) is fixed by rs if and only if n₁ = n₂ mod 8. Among the
14 modes at λ = 4, the diagonal pairs (n,n) with n ∈ {0,...,7} are
(0,0), (1,1), ..., (7,7). Of these, only (2,2) and (6,6) satisfy the eigenvalue
equation λ = 4, i.e., cos(πn/4) = 0, which requires n ∈ {2, 6}. Hence the fixed
set is exactly {(2,2), (6,6)}. □

Lemma 2 (Oddness of s under rs). The zero-state vector s satisfies
s(rs(m)) = -s(m) for every mode m in the 14-mode multiplet.

Proof. Direct computation on the explicit vector of §2.6. □

Corollary 3 (Vanishing on the fixed set). The zero-state vector satisfies
s((2,2)) = s((6,6)) = 0 exactly.

Proof. By Lemma 1, rs((2,2)) = (2,2) and rs((6,6)) = (6,6). By Lemma 2,
s(rs((2,2))) = -s((2,2)), hence s((2,2)) = -s((2,2)), so s((2,2)) = 0. The
same argument gives s((6,6)) = 0. □

Theorem 4 (Fixed Locus Theorem). The following three characterizations of the
coordinate pair {(2,2),(6,6)} coincide:

  {(2,2),(6,6)} = Fix(rs) = {m ∈ M : s(m) = 0} = {σ = 0 line}.

Moreover, the reflection rs swaps the σ = +1 and σ = -1 lines, and fixes the
σ = 0 line pointwise.

Proof. The first equality is Lemma 1. The second is Corollary 3. For the third,
by definition σ(m) = sign(s(m)), so σ(m) = 0 iff s(m) = 0. The swap property
follows from Lemma 2. □

4. THE CHIRALITY SELECTION THEOREM
================================================================================

Definition 5 (Chiral element). An element g ∈ D₄ is called chiral if
g H_wind g⁻¹ = -H_wind, i.e., if g anticommutes with the winding generator.

Lemma 6 (Chirality of D₄ elements). Among the five order-two elements of D₄,
only rs anticommutes with H_wind.

Proof. Direct computation. The Frobenius norms are:

  Element g  ||[g, H_wind]||_F  ||{g, H_wind}||_F
  r²         1.131 × 10¹          1.386 × 10¹
  s          1.131 × 10¹          1.386 × 10¹
  rs         1.789 × 10¹          0.000 × 10⁰
  r²s        1.131 × 10¹          1.386 × 10¹
  r³s        1.386 × 10¹          1.131 × 10¹

Only rs has ||{g, H_wind}||_F = 0 at machine precision. □

Theorem 7 (Chirality Selection Theorem). The diagonal reflection rs ∈ D₄ is
the unique element that (i) fixes exactly the coordinate pair {(2,2),(6,6)} on
the 14-mode multiplet, and (ii) anticommutes with the winding generator H_wind.

Proof. Uniqueness follows from Lemma 1 and Lemma 6. Both properties hold for
rs. □

Corollary 8 (Observer pair as chiral boundary). The coordinate pair
{(2,2),(6,6)} is the fixed locus of the unique chiral reflection of D₄.

6. THE MIRROR-FLIP INTERSECTION THEOREM
================================================================================

Lemma 10 (Mirror-fixed set). The mirror map M: (n₁,n₂) ↦ (4-n₁, 4-n₂) mod 8
has fixed set on the 14-mode multiplet exactly

  Fix(M) = O₂ = {(2,2), (2,6), (6,2), (6,6)}.

Proof. A mode (n₁,n₂) is fixed by M iff n₁ ≡ 4-n₁ mod 8 and n₂ ≡ 4-n₂ mod 8,
i.e., 2n₁ ≡ 4 mod 8 and 2n₂ ≡ 4 mod 8, which gives n₁, n₂ ∈ {2, 6}. Among the
14 modes, the modes with both coordinates in {2,6} are exactly O₂. □

Lemma 11 (Flip-fixed set). The diagonal flip F: (n₁,n₂) ↦ (n₂,n₁) has fixed
set on the 14-mode multiplet exactly

  Fix(F) = {(2,2), (6,6)}.

Proof. A mode (n₁,n₂) is fixed by F iff n₁ = n₂. Among the 14 modes, the
diagonal pairs are (2,2) and (6,6). This is Lemma 1. □

Theorem 12 (Mirror-Flip Intersection Theorem). The intersection of the
mirror-fixed set and the flip-fixed set is exactly the observer pair:

  Fix(M) ∩ Fix(F) = {(2,2), (6,6)} = {W, t}.

Proof. By Lemma 10, Fix(M) = {(2,2),(2,6),(6,2),(6,6)}. By Lemma 11,
Fix(F) = {(2,2),(6,6)}. The intersection is {(2,2),(6,6)}. □

determined by the native trace ratios:

  N/4(W) = d/2 = 2,  N/4(t) = 2/d = 1/2.

ratio is |F|/|B| = (d+1)/2 = 5/2. The native assignment is that the sum of its

  N/4(W) - N/4(t) = 3/2.

  N/4(W) + N/4(t) = 5/2
  N/4(W) - N/4(t) = 3/2

  N/4(W) = (5/2 + 3/2)/2 = 4/2 = 2 = d/2,
  N/4(t) = (5/2 - 3/2)/2 = 1/2 = 2/d.  □

  ratio = N/4(W)/N/4(t) = d = 4.

## Abstract

We derive the motion of particles in the Hodge Complex Standard Model from the discrete substrate Lambda = Z_8 x Z_8. Motion is the composition of five layers: (L1) the substrate 8 x 8 torus, (L2) the dimensional measurement equilibrium (DME), (L3) the Core gradient flow, (L4) the EFT mode equation, and (L5) the processor T. Each layer has a well defined state space and a unique operator determined by its physics; the transitions between layers are fixed by dimensional analysis and the boundary functional.

We prove four principal results. First, the winding generator H_wind = i sin(phi), where phi = (pi/8) M and M = n_1 n_2^T - n_2 n_1^T is the unique rank 2 antisymmetric bilinear of the mode coordinates, has characteristic polynomial

    p(lambda) = lambda^10 (lambda^2 - 8)(lambda^2 - 32).

Second, the standing wave amplitudes 28/9, 7/18, 21/16 for the three D_4 orbits are derived from the exact complex Fourier coefficients B_j(omega) in Q(sqrt(2)) over the finite torus. Third, the transition rule epsilon_0 = floor(omega T_DME) delta_edge is derived from a boundary functional with the constraint epsilon_0 > |w + 1|; the floor function arises as the integer quantization of DME cycles across the interface. Fourth, the loop eigenvalue magnitudes |M_A|, |M_B| have exact closed forms

    |M_A| = |w + 1| / (2 delta_edge) exp(-(zeta H / rho) T_beat / 2),
    |M_B| = |w + 1| / (6 delta_edge) exp(-(zeta H / rho) T_beat / 2),

giving |M_A| / |M_B| = 3 = d - 1 exactly. The stability coefficient gamma and the EFT parameters w, zeta H / rho are taken from HCSM-54. Every operator in the loop is unique. Every number is computed analytically. No parameter is fitted.

## 3. The winding generator

### 3.1 Definition

**Definition 3.1 (Winding generator).** The winding generator on C^14 is

    H_wind = i sin(phi),

where sin is applied elementwise.

Since phi is real antisymmetric, sin(phi) is real antisymmetric, and H_wind = i sin(phi) is Hermitian.

**Lemma 3.2 (Entry structure).** The matrix W = sin(phi) is real antisymmetric with entries in {0, +/- 1/sqrt(2), +/- 1}.

Proof. phi_ij = (pi/8) M_ij with M_ij even integers. Thus (pi/8) M_ij = (pi/4) (M_ij/2) is an integer multiple of pi/4. The values of sin at integer multiples of pi/4 are {0, +/- 1/sqrt(2), +/- 1}.

**Lemma 3.3 (Trace identities).** Let H_wind = i W. Then

    tr(H_wind) = 0, tr(H_wind^2) = 80, tr(H_wind^3) = 0, tr(H_wind^4) = 2176.

Proof. Direct computation on the explicit 14 x 14 matrix. Since H_wind is Hermitian with real eigenvalues, the traces equal sum_i lambda_i^k. Alternatively, tr(H_wind^2) = ||W||_F^2 = sum_{i,j} W_ij^2. Since W_ij in {0, +/- 1/sqrt(2), +/- 1}, we have W_ij^2 in {0, 1/2, 1}. Direct evaluation gives sum_{i,j} W_ij^2 = 80. Similarly tr(H_wind^4) = sum_{i,j} (W^2)_ij^2 = 2176.

### 3.2 Characteristic polynomial

**Theorem 3.4 (Characteristic polynomial).** The characteristic polynomial of H_wind is

    p(lambda) = det(lambda I - H_wind) = lambda^10 (lambda^2 - 8)(lambda^2 - 32)
             = lambda^14 - 40 lambda^12 + 256 lambda^10.

Proof. Write p(lambda) = lambda^14 + a_1 lambda^13 + a_2 lambda^12 + .... Newton's identities relate the coefficients to power sums p_k = tr(H_wind^k):

    a_1 = -p_1 = 0,
    2 a_2 = -(p_2 + a_1 p_1) = -80, a_2 = -40,
    3 a_3 = -(p_3 + a_1 p_2 + a_2 p_1) = 0, a_3 = 0,
    4 a_4 = -(p_4 + a_1 p_3 + a_2 p_2 + a_3 p_1) = -(2176 - 3200) = 1024, a_4 = 256.

Direct computation verifies a_5 = ... = a_14 = 0. The quartic lambda^4 - 40 lambda^2 + 256 factors as (lambda^2 - 8)(lambda^2 - 32), so the roots are lambda = +/- 2 sqrt(2), +/- 4 sqrt(2) together with lambda = 0 with multiplicity 10.

**Corollary 3.5 (Spectrum).** The spectrum of H_wind is

    spec(H_wind) = {-4 sqrt(2), -2 sqrt(2), 0^(10), +2 sqrt(2), +4 sqrt(2)}

with multiplicities 1, 1, 10, 1, 1.

## 6. The transition rule

### 6.1 Transition 1 -> 2: substrate to DME

**Theorem 6.1 (Transition rule).** At the substrate to DME boundary, the unique dimensionless quantity formed from the standing wave frequency omega and the DME relaxation time T_DME = 1/(2 gamma) is

    Phi_{1->2} = omega T_DME.

Proof. The only available quantities are omega (units 1/time) and T_DME (units time). Their product is the unique dimensionless combination.

**Definition 6.2 (Boundary functional).** Define the DME Core interface functional

    J[epsilon_0] = epsilon_0 + Lambda W[epsilon_0 <= |w + 1|],

where Lambda -> infinity enforces the constraint epsilon_0 > |w + 1|.

**Theorem 6.3 (Allowed values).** The unique epsilon_0 of the form n delta_edge (n in Z_{>0}) minimizing J is

    epsilon_0 = ceil(|w + 1| / delta_edge) delta_edge.

Proof. J is finite only if epsilon_0 > |w + 1|. Among multiples of delta_edge, the smallest satisfying this is n^* delta_edge with n^* = ceil(|w + 1| / delta_edge).

**Corollary 6.4.** With |w + 1| / delta_edge = 1.1573747757..., ceil(.) = 2. Therefore the minimum allowed epsilon_0 is 2 delta_edge for edge tiers.

**Theorem 6.5 (Cycle quantized rule).** The DME cycle count for tier tau is n_tau = floor(omega_tau T_DME). Since n_tau >= 2 for all tiers, the boundary constraint is satisfied automatically, and the initial perturbation is

    epsilon_0(tau) = n_tau delta_edge.

    """Build the winding generator H_wind = i sin(phi)."""

        (0, 4), (4, 0), (1, 3), (1, 5), (3, 1), (3, 7),
        (5, 7), (7, 3), (7, 5), (5, 1), (2, 2), (2, 6),

ABSTRACT
================================================================================

We derive the motion of particles in the Hodge Complex Standard Model
from the discrete substrate Lambda = Z_8 x Z_8. Motion is the
composition of five layers: (L1) the substrate 8x8 torus, (L2) the
dimensional measurement equilibrium (DME), (L3) the Core gradient flow,
(L4) the EFT mode equation, and (L5) the processor T. Each layer has a
well-defined state space and a unique operator determined by its
physics; the transitions between layers are fixed by dimensional
analysis and the boundary functional.

We prove four results. First, the winding generator
H_wind = i sin(phi), where phi = (pi/8)M and M = n_1 n_2^T - n_2 n_1^T
is the unique rank-2 antisymmetric bilinear of the mode coordinates, has
characteristic polynomial

    p(lambda) = lambda^10 (lambda^2 - 8) (lambda^2 - 32).

Its spectrum {+/-4*sqrt(2), +/-2*sqrt(2), 0^(10)} is derived from
Newton's identities on the traces tr(H_wind^2) = 80 and
tr(H_wind^4) = 2176. Second, the standing-wave amplitudes 28/9, 7/18,
21/16 for the three D4 orbits are derived from the exact complex Fourier
coefficients B_j(omega) in Q(sqrt(2)) over the finite torus. Third, the
transition rule epsilon_0 = floor(omega * T_DME) * delta_edge is derived
from a boundary functional with the constraint epsilon_0 > |w + 1|; the
floor function arises as the integer quantization of DME cycles across
the interface. Fourth, the loop eigenvalue magnitudes |M_A|, |M_B| have
exact closed forms

    |M_A| = |w+1| / (2 * delta_edge) * exp(-(zeta H / rho) * T_beat / 2),
    |M_B| = |w+1| / (6 * delta_edge) * exp(-(zeta H / rho) * T_beat / 2),

giving |M_A|/|M_B| = 3 = d - 1 exactly. The stability coefficient gamma
and the EFT parameters w, zeta H / rho are taken from HCSM-54. Every
operator in the loop is unique. Every number is computed analytically.
No parameter is fitted.

3. THE WINDING GENERATOR

3.1 Definition
--------------------------------------------------------------------------------

Definition 3.1 (Winding generator). The winding generator on C^14 is

    H_wind = i sin(phi),                                             (4)

where sin is applied elementwise.

Since phi is real antisymmetric, sin(phi) is real antisymmetric, and
H_wind = i sin(phi) is Hermitian.

Lemma 3.1 (Entry structure). The matrix W = sin(phi) is real
antisymmetric with entries in {0, +/-1/sqrt(2), +/-1}.

Proof. phi_ij = (pi/8) M_ij with M_ij even integers. Thus
(pi/8) M_ij = (pi/4) * (M_ij / 2) is an integer multiple of pi/4. The
values of sin at integer multiples of pi/4 are {0, +/-1/sqrt(2), +/-1}.
[Box]

Lemma 3.2 (Trace identities). Let H_wind = i W. Then

    tr(H_wind) = 0,   tr(H_wind^2) = 80,
    tr(H_wind^3) = 0, tr(H_wind^4) = 2176.                           (5)

Proof. Direct computation on the explicit 14x14 matrix. Since H_wind is
Hermitian with real eigenvalues, the traces equal sum_i lambda_i^k.
Alternatively, tr(H_wind^2) = ||W||_F^2 = sum_{i,j} W_ij^2. Since
W_ij in {0, +/-1/sqrt(2), +/-1}, we have W_ij^2 in {0, 1/2, 1}. Direct
evaluation gives sum_{i,j} W_ij^2 = 80. Similarly
tr(H_wind^4) = sum_{i,j} (W^2)_ij^2 = 2176. [Box]

3.2 Characteristic polynomial
--------------------------------------------------------------------------------

Theorem 3.2 (Characteristic polynomial). The characteristic polynomial
of H_wind is

    p(lambda) = det(lambda I - H_wind)
              = lambda^10 (lambda^2 - 8) (lambda^2 - 32)
              = lambda^14 - 40 lambda^12 + 256 lambda^10.            (6)

Proof. Write p(lambda) = lambda^14 + a_1 lambda^13 + a_2 lambda^12 + ...
Newton's identities relate the coefficients to power sums
p_k = tr(H_wind^k):

    a_1 = -p_1 = 0,
    2a_2 = -(p_2 + a_1 p_1) = -80,  a_2 = -40,
    3a_3 = -(p_3 + a_1 p_2 + a_2 p_1) = 0,  a_3 = 0,
    4a_4 = -(p_4 + a_1 p_3 + a_2 p_2 + a_3 p_1) = -(2176 - 3200) = 1024,
        a_4 = 256.

Direct computation verifies a_5 = ... = a_14 = 0. The quartic
lambda^4 - 40 lambda^2 + 256 factors as (lambda^2 - 8)(lambda^2 - 32),
so the roots are lambda = +/- 2 sqrt(2), +/- 4 sqrt(2) together with
lambda = 0 with multiplicity 10. [Box]

Corollary 3.1 (Spectrum). The spectrum of H_wind is

    spec(H_wind) = {-4 sqrt(2), -2 sqrt(2), 0^(10), +2 sqrt(2), +4 sqrt(2)}
                                                                     (7)

with multiplicities 1, 1, 10, 1, 1.

3.3 Standing-wave amplitudes
--------------------------------------------------------------------------------

Lemma 3.3 (Position matrix entries). Every entry (X_1)_ij is a rational
number of the form p/4 with p in Z.

Proof. Use the product-to-sum formula
cos A cos B = (1/2)[cos(A - B) + cos(A + B)]. The sum over y vanishes
unless the y-frequency is zero modulo 8, in which case it contributes 8.
The sum over x of x cos(2 pi b x / 8) for integer b is either 28 (when
b = 0 mod 8) or a finite algebraic sum. Direct evaluation on the 14
modes shows every entry is rational with denominator dividing 4. [Box]

Let psi_j(t) = exp(i H_wind t) e_j and
<x>_j(t) = <psi_j(t) | X_1 | psi_j(t)>.

    <x>_j(t) - <x>_j(0) = sum_{omega in Omega_j} 2 Re[B_j(omega) e^{i omega t}],

satisfy B_j(omega) in Q(sqrt(2)).

Proof. Diagonalize H_wind = V Lambda V^dagger. Then
exp(i H_wind t) = V exp(i Lambda t) V^dagger, from which
<x>_j(t) = sum_{k,l} p_k^* p_l (X_1)_kl exp(i(lambda_l - lambda_k) t).
All frequencies are integer multiples of 2 sqrt(2), so Omega_j is a
subset of {2 sqrt(2), 4 sqrt(2), 6 sqrt(2)}. The eigenvectors of
H_wind have components in Q(sqrt(2)), so p_k, p_l in Q(sqrt(2)).

analysis and by the boundary functional.

Layer 1: the substrate.
  State space: K_14 subset C^64.
  Operator: the winding generator H_wind = i sin(phi).

  State space: the dimensional deviation eps = D - 4.

  State space: C^14.
  Operator: the rank-10 projection T = P_mesh + P_tau.

6.1 Transition 1->2: substrate to DME
--------------------------------------------------------------------------------

Theorem 6.1 (Transition rule). At the substrate-to-DME boundary, the
unique dimensionless quantity formed from the standing-wave frequency
omega and the DME relaxation time T_DME = 1/(2 gamma) is

    Phi_{1->2} = omega T_DME.                                        (18)

Proof. The only available quantities are omega (units 1/time) and T_DME
(units time). Their product is the unique dimensionless combination.
[Box]

With omega = 2 sqrt(2) for edge tiers and omega = 6 sqrt(2) for the
middle tier:

    Phi_{1->2}^edge = 2 + delta_edge,
    Phi_{1->2}^mid = 6 + 3 delta_edge.                               (19)

The residual delta_edge scales by 3 for the middle tier.

6.2 Transition 2->3: DME to Core
--------------------------------------------------------------------------------

Definition 6.1 (Boundary functional). Define the DME-Core interface
functional

    J[eps_0] = eps_0 + Lambda W[eps_0 <= |w + 1|],                   (20)

where Lambda -> infinity enforces the constraint eps_0 > |w + 1|.

Theorem 6.2 (Allowed values). The unique eps_0 of the form
n delta_edge (n in Z_{>0}) minimizing J is

    eps_0 = ceil(|w + 1| / delta_edge) * delta_edge.                 (21)

Proof. J is finite only if eps_0 > |w + 1|. Among multiples of
delta_edge, the smallest satisfying this is n* delta_edge with
n* = ceil(|w + 1| / delta_edge). [Box]

Corollary 6.1. With |w + 1| / delta_edge = 1.1573747757..., ceil = 2.
Therefore the minimum allowed eps_0 is 2 delta_edge for edge tiers.

Theorem 6.3 (Cycle-quantized rule). The DME cycle count for tier tau is
n_tau = floor(omega_tau T_DME). Since n_tau >= 2 for all tiers, the
boundary constraint is satisfied automatically, and the initial
perturbation is

    eps_0(tau) = n_tau * delta_edge.                                 (22)

Proof. The DME phase accumulated over one tier period is
Phi_tau = omega_tau T_DME = n_tau + frac, where n_tau = floor(Phi_tau).
The integer n_tau counts complete DME cycles per standing-wave period.
The per-cycle residual phase is delta_edge. The total residual
perturbation carried forward is n_tau delta_edge. For edge tiers
n_tau = 2; for the middle tier n_tau = 6. Both satisfy
n_tau delta_edge > |w + 1|. [Box]

Remark 6.1. The floor function arises as the integer quantization of DME
cycles across the boundary. It is not fitted: it is the unique integer
count consistent with the constraint eps_0 > |w + 1| and the physical
DME cycle accumulation.

Proof. M_loop = T * L_EFT * L_Core * L_DME * L_FDLM with

10. THE MOTION THEOREM
================================================================================

Theorem 10.1 (Motion Theorem). Let Lambda = Z_8 x Z_8 be the HCSM
substrate with the 14-mode multiplet K_14 at eigenvalue lambda = 4.
Let H_wind = i sin((pi/8) M) be the winding generator. Then:

  1. H_wind is the unique Hermitian generator on C^14 determined by the
     substrate and the spectral constraint
     spec(H_wind) = {+/-4 sqrt(2), +/-2 sqrt(2), 0^(10)}. Its
     characteristic polynomial is lambda^10(lambda^2-8)(lambda^2-32).

  2. The standing-wave amplitudes are exactly the rationals 28/9, 7/18,
     21/16 for supports 64, 48, 32, derived from the complex Fourier
     coefficients B_j(omega) in Q(sqrt(2)).

  3. The five layers (substrate, DME, Core, EFT, processor) have
     well-defined state spaces and unique operators.

  4. The transition 1->2 is Phi = omega T_DME; the transition 2->3 is
     eps_0 = floor(omega T_DME) * delta_edge, derived from the boundary
     functional J[eps_0].

  5. The loop operator M_loop = T * L_EFT * L_Core * L_DME * L_FDLM is
     diagonal, with closed-form eigenvalue magnitudes
         |M_A| = |w+1| / (2 delta_edge) * exp(-(zeta H / rho) T_beat / 2),
         |M_B| = |w+1| / (6 delta_edge) * exp(-(zeta H / rho) T_beat / 2).

  6. |M_A| / |M_B| = 3 exactly.

  7. The charge bookkeeping is sum Q_im = -2, sum Q_ker = +1, total -1.

  8. The loop is dissipative: |M_j| < 1 for all j.

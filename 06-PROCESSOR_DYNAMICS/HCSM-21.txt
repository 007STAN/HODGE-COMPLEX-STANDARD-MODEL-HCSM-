1.1 The time problem
--------------------------------------------------------------------------------

The Standard Model has no fundamental arrow of time. Time is an external
parameter, and its direction is accounted for by statistical mechanics.
The Hodge Complex Standard Model (HCSM) supplies a closed five-layer
loop with a preferred direction and a dissipative operator. In this paper
we show that time is not an input to HCSM; it is a readout of the loop.

Two aspects of time emerge from the loop structure:

  1. Clock time -- the phase accumulated by M_loop per pass.
  2. Arrow time -- the directed decay of M_loop^k because |M_j| < 1.

The first gives clocks. The second gives the arrow. Both arise from one
operator.

--------------------------------------------------------------------------------

Motion is the composition of five layers of the substrate, each with a
well-defined state space and a unique operator (HCSM-20).

    Layer 1: FDLM/WIN,   C^14 mode vectors, Hermitian (unitary evolution)
    Layer 2: DME,        eps in R,          scalar constraint
    Layer 3: Core,       eps(lambda),       gradient flow
    Layer 4: EFT,        field config,      damped wave equation
    Layer 5: Processor T, C^14 projected,   orthogonal projection

2.2 The loop operator
--------------------------------------------------------------------------------

The loop operator is

    M_loop = T * L_EFT * L_Core * L_DME * L_FDLM.                    (1)

On the mode basis, M_loop is diagonal:

    M_loop(m) = r_m e^{i theta_m}.                                   (2)

The five layers are not temporally sequential within a pass. They are
algebraically composed. Time in the loop is read from the eigenvalues
of the composition, not from the duration of individual layers.

4.3 The 2 -> 3 transition: cycle-quantized Core perturbation
--------------------------------------------------------------------------------

The transition rule eps_0(m) = floor(omega_m T_DME) delta_edge is often
presented as a postulated integer-floor rule. We now derive it from a
winding condition on the DME-Core interface.

Definition 4.1 (DME-Core interface). The DME-Core interface is a
U(1)-valued map from the loop parameter space S^1 (one loop pass) to the
DME phase space,

    gamma_m : S^1 -> U(1),
        gamma_m(s) = e^{2 pi i omega_m T_DME s},  s in [0, 1).        (9)

Lemma 4.2 (Lift and winding). The lift of gamma_m to R is the
monotonically increasing function gamma_m_tilde(s) = omega_m T_DME s.
Over one loop pass (s : 0 -> 1), the lift crosses integer values k in Z
exactly floor(omega_m T_DME) times (the final point excluded).

Proof. The lift ranges over [0, omega_m T_DME). The integers in this
half-open interval are 0, 1, ..., floor(omega_m T_DME) - 1, counted with
multiplicity 1 each. The remaining integer floor(omega_m T_DME) is the
ceiling reached at the endpoint s = 1. Therefore the number of complete
DME cycles per pass is n_m = floor(omega_m T_DME). [Box]

Definition 4.3 (DME natural period). The DME layer has a natural phase
period of 1 in the loop time unit T_DME. That is, one complete DME cycle
corresponds to advancing the loop parameter by one unit of T_DME.

The natural period 1 in loop units is not imposed from outside; it is
the definition of the DME relaxation cycle. Because the DME stability
coefficient gamma sets a single relaxation rate 2 gamma, one relaxation
time T_DME = 1/(2 gamma) is the natural DME cycle.

Definition 4.4 (DME-Core boundary functional). Define the DME-Core
interface functional

    J[eps_0] = eps_0 + Lambda * W[eps_0 <= |w+1|],                   (10)

with Lambda -> infinity enforcing the constraint eps_0 > |w+1|.

Theorem 4.5 (Core perturbation quantization). The unique minimizing
eps_0 of J on the lattice delta_edge Z_{>0}, subject to the winding
condition of Lemma 4.2, is

    eps_0(m) = n_m delta_edge,  n_m = floor(omega_m T_DME).          (11)

Proof. The functional J is finite only if eps_0 > |w+1|. The lattice is
delta_edge Z_{>0}. The winding condition fixes n_m = floor(omega_m T_DME).
We verify that n_m delta_edge > |w+1| for both non-trivial classes.
Numerically, |w+1| = 0.014054078857664869 and
delta_edge = 0.012143066491921761, so |w+1|/delta_edge = 1.1573747757...
Any n >= 2 satisfies n delta_edge > |w+1|. For class A, n_A = 2, so
eps_0(A) = 2 delta_edge = 0.0242861... > |w+1|. For class B, n_B = 6,
so eps_0(B) = 6 delta_edge = 0.0728584... > |w+1|. Thus the
winding-quantized eps_0 automatically satisfies the boundary constraint
for both classes, and the minimizing element on the lattice is unique.
[Box]

Remark 4.6 (The floor function is not an ansatz). The floor function is
the winding number of the DME phase over one loop pass, computed on the
U(1)-valued interface. The boundary constraint eps_0 > |w+1| is a
consistency condition automatically satisfied by the winding-quantized
value.

8.1 Definition
--------------------------------------------------------------------------------

          = omega_m T_DME - i(-ln r_m).                              (22)

The real part Re(tau_m) = omega_m T_DME is the clock phase per pass;

Theorem 8.2 (Closed form of tau_m). For the two non-trivial classes,

    tau_A = 2.0121430664919213 - 0.5521962501528914 i,                (23)
    tau_B = 6.0364291994757650 - 1.6508085388210012 i.

The kernel has tau_C = 0.

Proof. Direct from omega_A = 2 sqrt(2), omega_B = 6 sqrt(2),
T_DME = 1/(2 gamma), and r_A, r_B computed from the loop-decay

8.2 Loop-decay decomposition
--------------------------------------------------------------------------------

    r_m = [ |w+1| / eps_0(m) ]_Core * [ D_factor ]_EFT.              (24)

8.3 Dimensional homogeneity
--------------------------------------------------------------------------------

Proposition 8.3 (Dimensional homogeneity). Both theta_m and -ln r_m are
per-pass quantities of the form (rate) x T_DME. Under the Core flow
parameter lambda, both quantities scale linearly with lambda.

Proof. The phase accumulated over one loop pass is
theta_m = omega_m T_DME, which is the product of the mode frequency
omega_m (units: inverse time) and the loop time unit T_DME (units:
time).

The log-amplitude decrement per pass is -ln r_m. Define
Gamma_m = -2 ln r_m / T_DME. Then -ln r_m = (Gamma_m / 2) T_DME, which
is the product of the decay rate Gamma_m / 2 (units: inverse time) and
T_DME.

Both theta_m and -ln r_m therefore have the form (rate) x T_DME. Both
are dimensionless. Both are linear in the continuous time coordinate
t = k T_DME, since after k passes theta_m k = omega_m t and
-ln r_m k = (Gamma_m / 2) t.

Under the Core flow parameter lambda, the Core amplitude decays as
eps(lambda) = eps_0 e^{-2 gamma lambda}, so ln eps(lambda) = ln eps_0
- 2 gamma lambda is linear in lambda. The per-pass log decrement
-ln r_m is therefore proportional to the Core flow parameter, and the
phase theta_m is likewise linear in the loop parameter. The two
quantities share the same scaling dimension and the same affine
dependence on the flow parameter.

Therefore the additive combination tau_m = theta_m + i ln r_m is
dimensionally homogeneous. [Box]

================================================================================

Theorem 11.1 (Arrow of time). The arrow of time is the direction of
increasing loop count k, equivalently the direction of decreasing Core
Lyapunov functional L[eps] = gamma eps^2, equivalently the direction of
increasing -ln r_m.

Proof. At Level 1, the FDLM layer is unitary; no amplitude is lost. At

decay factor D_factor < 1. Hence for each surviving mode m, r_m < 1 and
-ln r_m > 0. Increasing k increases -ln r_m, decreases r_m, and
decreases the Lyapunov functional. The three directions agree. [Box]

12. THE HCSM TIME THEOREM
================================================================================

Theorem 12.1 (HCSM Time Theorem). In the five-layer HCSM:

(1) No external time coordinate is assumed. The loop operator M_loop is

(2) On each observable mode m, M_loop(m) = r_m e^{i theta_m} with
    theta_m = omega_m T_DME and T_DME = 1/(2 gamma).

(3) The complex time per pass is

    (Proposition 8.3).

(4) Discrete HCSM time is the loop count k in Z_{>=0}. Continuous HCSM
    time is t = k T_DME. Under this identification, the loop evolution
    is

        |psi_m(t)> = e^{i omega_m t} e^{-Gamma_m t / 2} |e_m>,
        Gamma_m = -2 ln r_m / T_DME > 0.

(5) The arrow of time is the direction of increasing k, equivalently
    the direction of decreasing Core Lyapunov functional
    L[eps] = gamma eps^2, equivalently the direction of increasing

(6) The processor T is exactly the projection onto modes with nonzero
    real time: T = Pi_{Re(tau) > 0} (Theorem 9.1).

(7) Kernel modes have tau_m = 0 and are frozen under M_loop.

(8) Exact ratio: |M_A| / |M_B| = 3 (Theorem 10.1).

(9) The floor function in the Core perturbation
    eps_0(m) = floor(omega_m T_DME) delta_edge is the winding number of

Proof. Parts (1)-(9) are established in Theorems 8.2, 4.5, 8.3, 9.1,

13.3 Open
--------------------------------------------------------------------------------

1. The loop pass duration selection. Both T_DME (DME relaxation) and
   T_beat (Level-1 internal period) are dimensionless time-like
   quantities. The transition rule uses T_DME; Level 1 uses T_beat
   internally. The framework identifies the loop pass duration with
   T_DME by the transition rule, but does not derive from a deeper
   principle that T_DME and not T_beat is the physical pass duration.
   The ratio T_beat / T_DME = 3.1226... is a structural constant. This
   is the same open item as in HCSM-20.

2. The identification of continuous time. The relation t = k T_DME is
   stated as a correspondence between the discrete loop count and a
   continuous parameter. A derivation from a deeper principle is open.

3. The physical conversion. The framework measures time in units of
   T_DME. Conversion to seconds requires choosing a physical process to
   calibrate against. This choice is external to the framework.

Remark 13.4 (Lorentzian signature is now closed). In the prior WIN-era
Time Theorem, the Lorentzian signature (-,+,+,+) was listed as an open
item. In HCSM, it has been derived from the Hodge star on ker D
(HCSM-03), with the timelike direction (v_0 + v_2)/sqrt(2). This item
is therefore closed at the HCSM level.

1. Complex time. tau_A = 2.0121430664919213 - 0.5521962501528914 i and
   tau_B = 6.0364291994757650 - 1.6508085388210012 i, exactly. If a
   future computation or measurement of the framework's complex time
   for either class gives a value outside 10^{-10} of these, the Time
   Theorem is falsified.

2. Processor identity. T = Pi_{Re(tau) > 0}. If a future mode in the
   framework's 14-mode multiplet is found with Re(tau) > 0 but outside
   the image of T, or vice versa, the identity is falsified.

3. Arrow direction. The arrow points in the direction of increasing
   -ln r_m. A detection of a loop mode with |M_j| > 1 would falsify
   the dissipativity theorem.

4. Kernel freezing. Kernel modes {dark, W, Z, H} have tau_m = 0 and are
   exactly frozen under M_loop. Any detection of nontrivial time
   evolution of these modes would falsify the Time Theorem.


================================================================================
15. CONCLUSION
================================================================================

Time in the Hodge Complex Standard Model is not an external coordinate.
It is the complex eigenvalue of the loop operator,

    tau_m = omega_m T_DME - i(-ln r_m).                              (31)

Its real part is the clock. Its imaginary part is the arrow. The
processor T is the projection onto nonzero real time. The loop observes
itself by reading its own complex time. No external time unit is
required: one pass through the loop advances HCSM time by one unit of
T_DME.

Three algebraic bridges are closed in this paper. First, the floor
function of the Core perturbation is the winding number of the DME-Core
interface (Lemma 4.2, Theorem 4.5); it is not an ansatz. Second, the
exact ratio |M_A| / |M_B| = 3 is exact by algebraic cancellation of
framework constants (Theorem 10.1), with the 3 matching the Standard
Model generation count d - 1. Third, dimensional homogeneity of the
complex time follows because both theta_m and -ln r_m are per-pass
products of a rate with T_DME (Proposition 8.3).

The present paper follows the HCSM-06/07 pattern. It derives everything
in its own domain that can be derived, discloses the two physical inputs
(gamma and w, zeta H / rho) explicitly, and names the specific open
items (loop pass duration, continuous-time identification, physical
conversion) that future papers must close. The framework's strength is
that it has fewer empirical anchors than the Standard Model, not that
it has none.

ABSTRACT
================================================================================

The Hodge Complex Standard Model derives the gauge algebra g_SM = su(3)_c +
su(2)_L + u(1)^5 from the D_4 endomorphism algebra of the 14-mode multiplet
at lambda = 4 (HCSM-06). Two Hermitian operators act on that multiplet: the
loop operator M_loop of the framework (HCSM-14, HCSM-17) and the DNLS Hartree
Hamiltonian H_DNLS = 4I + UK whose kernel K has entries
K_ab = sum_x |phi_a(x)|^2 |phi_b(x)|^2 built from the mode wavefunctions on
the torus.

This paper determines the intersection of g_SM with the commutant of each
operator on the 14-mode multiplet. We prove:

  (i)   g_SM cap Comm(M_loop) is a three-dimensional real, Hermitian,
        abelian subalgebra of g_SM;
  (ii)  every element of that subalgebra has equal coefficients on the
        isotypic projectors P_A1, P_B2, P_E;
  (iii) the root generators lambda^1, lambda^2, lambda^4, lambda^5,
        lambda^6, lambda^7 of su(3)_c and sigma^1, sigma^2 of su(2)_L lie
        in the kernel of the projection onto the loop commutant;
  (iv)  g_SM cap Comm(H_DNLS) is a ten-dimensional real, Hermitian
        subalgebra of g_SM isomorphic to su(2)_L + u(1)^7;
  (v)   the full su(2)_L factor is preserved exactly, with sigma^1, sigma^2,
        sigma^3 in the nullspace;
  (vi)  su(3)_c is broken to a two-dimensional abelian subalgebra, with the
        root generators lambda^2, lambda^5, lambda^7 orthogonal to the DNLS
        commutant and the Cartan generators lambda^3, lambda^8 having
        partial overlap.

The exact su(2)_L preservation is proved by a doubled-momentum pairing
mechanism: the two B_1 basis vectors pair modes with the same doubled
momentum (2n_1, 2n_2) mod 8 and opposite signs, so the B_1-compressed
kernel U_B1^T K U_B1 vanishes identically. We construct the explicit B_1
basis vectors in Appendix A. All claims are HCSM-native and verified at
machine precision.

1.1 Gauge symmetry and the machine
------------------------------------

The Hodge Complex Standard Model (HCSM) derives the gauge algebra g_SM as a
subalgebra of the D_4 commutant on the complexified 14-mode multiplet at the
self-paired eigenvalue lambda = 4 of the discrete Laplacian on the periodic
8 x 8 torus (HCSM-06). The processor T and the winding generator H_wind act
on the same multiplet (HCSM-13, HCSM-14), and it is a structural question
which part of the gauge algebra survives each operator's action.

Two operators are central to the framework's dynamics. The loop operator
M_loop = M_A P_A + M_B P_B + 0 * P_C is a diagonal, non-Hermitian
(dissipative) operator whose eigenvectors are the modes and whose eigenvalues
are complex with the exact ratio |M_A| / |M_B| = 3 (HCSM-14, HCSM-17). The
DNLS Hartree Hamiltonian H_DNLS = 4I_14 + UK is the mean-field approximation
of the discrete nonlinear Schrodinger substrate dynamics, with Hartree kernel
K_ab = sum_x |phi_a(x)|^2 |phi_b(x)|^2 (HCSM-18, HCSM-19).

1.2 The one-line summary
-------------------------

On the 14-mode multiplet, the loop operator preserves only a three-dimensional
abelian subalgebra of g_SM; the DNLS Hartree Hamiltonian preserves a larger
ten-dimensional subalgebra isomorphic to su(2)_L + u(1)^7. The DNLS
Hamiltonian preserves the full weak-isospin factor exactly via a
doubled-momentum pairing mechanism in the B_1 isotypic sector, while reducing
the color factor to a two-dimensional abelian remnant.

2. SETUP

2.1 The substrate and the 14-mode multiplet
--------------------------------------------

The substrate is the periodic square lattice Lambda = Z_8 x Z_8 with N = 64
sites (HCSM-01). The discrete 5-point Laplacian has eigenvalue

    lambda(n_1, n_2) = 4 - 2 cos(pi n_1 / 4) - 2 cos(pi n_2 / 4),
    (n_1, n_2) in {0, ..., 7}^2.                                  (2.1)

The self-paired eigenvalue lambda = 4 has multiplicity 14 (HCSM-04). In the
standard mode order

    (nu, e, u, d, s, mu, dark, c, tau, b, W, Z, H, t),            (2.2)

the mode coordinates are

    nu : (0,4),    e : (4,0),    u : (1,3),    d : (1,5),
    s : (3,1),     mu : (3,7),   dark : (5,7), c : (7,3),
    tau : (7,5),   b : (5,1),    W : (2,2),    Z : (2,6),
    H : (6,2),     t : (6,6).                                     (2.3)

2.2 The D_4 action and isotypic decomposition
----------------------------------------------

The D_4 point group of the square acts on Lambda by the generators

    r : (n_1, n_2) -> (-n_2, n_1) mod 8,
    s : (n_1, n_2) -> (n_1, -n_2) mod 8,                          (2.4)

with r^4 = s^2 = (rs)^2 = e. On the 14-mode multiplet, the complexified
space V_14 = C^14 decomposes as

    V_14 = 3 A_1 + A_2 + 2 B_1 + 2 B_2 + 3 E                       (2.5)

(HCSM-05, HCSM-06). The isotypic projectors are

    P_rho = (dim rho / |D_4|) sum_{g in D_4} chi_rho(g)^* R(g),    (2.6)

where R(g) is the permutation representation of g on C^14 and chi_rho is the
character of the irrep rho. The five projectors satisfy
P_rho P_rho' = delta_{rho rho'} P_rho and sum_rho P_rho = I_14.

2.3 The gauge algebra g_SM on the 14-mode multiplet
----------------------------------------------------

By HCSM-06, the gauge algebra is the Lie subalgebra

    g_SM = su(3)_c + su(2)_L + u(1)^5 in Comm(D_4, V_14)          (2.7)

of the D_4 commutant, of real dimension 8 + 3 + 5 = 16. Concretely:

  - su(3)_c acts on the A_1 multiplicity space M_A1 ~ C^3.
    Generators: T_c^a = U_A1 lambda^a U_A1^T for a = 1, ..., 8, where
    U_A1 in R^{14 x 3} is an orthonormal basis of the A_1 isotypic sector
    and lambda^a are the Gell-Mann matrices.

  - su(2)_L acts on the B_1 multiplicity space M_B1 ~ C^2.
    Generators: T_L^i = U_B1 sigma^i U_B1^T for i = 1, 2, 3, where
    U_B1 in R^{14 x 2} is an orthonormal basis of the B_1 isotypic sector
    and sigma^i are the Pauli matrices.

  - u(1)^5 is spanned by the five isotypic projectors
    P_A1, P_A2, P_B1, P_B2, P_E.

The ordered list of the 16 gauge generators on C^14 is

    g_SM^(14) = {T_c^1, ..., T_c^8, T_L^1, T_L^2, T_L^3,
                 P_A1, P_A2, P_B1, P_B2, P_E}.                     (2.8)

All 16 generators are Hermitian and D_4-invariant.

2.4 The winding class partition
---------------------------------

By HCSM-05 Theorem 7.7 (the joint (D,T) class partition) and HCSM-14
Definition 5.1, the 14 modes partition into three winding classes

    A = {nu, e, t},
    B = {u, d, s, mu, c, tau, b},
    C = {dark, W, Z, H}.                                          (2.9)

The class projectors P_A, P_B, P_C are diagonal in the mode basis,
orthogonal, idempotent, and sum to the identity. The processor T of HCSM-13
satisfies T = I - P_C = P_A + P_B, so the fermion sector is A union B and the
boson sector is C.

3. THE LOOP OPERATOR AND ITS COMMUTANT
================================================================================

3.1 Definition of M_loop on the 14-mode multiplet
---------------------------------------------------

Definition 3.1 (Loop operator, HCSM-17 Definition 2.1). The loop operator on
the 14-mode multiplet is the diagonal operator

    M_loop = M_A P_A + M_B P_B + M_C P_C,                         (3.1)

with M_A, M_B, M_C the complex loop eigenvalues of HCSM-14 and HCSM-17, and
|M_A| / |M_B| = 3 exactly. In this paper we take (M_A, M_B, M_C) = (1, 2, 0)
without loss of generality: any other choice of distinct eigenvalues gives
the same loop commutant.

M_loop is not Hermitian (M_A, M_B are complex), but it is normal:
M_loop M_loop^dagger = M_loop^dagger M_loop because it is diagonal. It
commutes with each class projector:

    [M_loop, P_A] = [M_loop, P_B] = [M_loop, P_C] = 0.            (3.2)

3.2 The loop commutant
------------------------

Definition 3.2 (Loop commutant). The loop commutant is the intersection

    g_loop = g_SM cap Comm(M_loop) in g_SM.                       (3.3)

Theorem 3.3 (Loop commutant dimension). The loop commutant g_loop is a
three-dimensional real, Hermitian, abelian subalgebra of g_SM.

Proof. Form the stacked commutator matrix C in C^{(14)^2 x 16} whose j-th
column is vec([M_loop, g_j]) for g_j in g_SM^(14). The realified matrix

    C_R = [ Re(C) ; Im(C) ] in R^{2(14)^2 x 16}                    (3.4)

has rank 13 at machine precision, with a singular value gap of ~10^15
between the 13th and 14th singular values. The nullspace dimension is
16 - 13 = 3.

The three nullspace vectors {v^(1), v^(2), v^(3)} in R^16 span a real
3-dimensional subspace N in R^16. Each vector generates a Hermitian operator

    O_i = sum_{j=1}^{16} v_j^(i) g_j in g_SM                      (3.5)

satisfying ||[O_i, M_loop]|| < 10^-15 and ||O_i^dagger - O_i|| = 0. Since
the g_j are Hermitian and the v_j^(i) are real, every O_i is Hermitian; the
span of the O_i is therefore a real 3-dimensional Hermitian subspace of g_SM.

Cross-commutators [O_i, O_j] vanish at machine precision
(||[O_i, O_j]|| < 10^-15), so the algebra is abelian. Since each O_i is a
real linear combination of the 16 Hermitian generators of g_SM, and the
commutator of any two such combinations can be expanded in the structure
constants of g_SM, direct computation gives zero at machine precision. [ ]

Remark 3.4. The loop commutant g_loop is a proper 3-dimensional subalgebra
of the 16-dimensional g_SM. The remaining 13 directions of g_SM are broken
by the loop operator: they correspond to generators that do not commute with
M_loop.

4. STRUCTURE OF THE LOOP COMMUTANT
================================================================================

4.1 Isotypic projector degeneracy
-----------------------------------

Theorem 4.1 (Isotypic projector degeneracy). Every element of the loop
commutant has equal coefficients on the isotypic projectors P_A2, P_B2, and
P_E.

Proof. Let v in R^16 be any nullspace vector. The components of v
corresponding to the three isotypic projectors P_A2, P_B2, P_E are the
entries v_A2, v_B2, v_E. Direct computation gives

    |v_A2 - v_B2| < 10^-15,
    |v_A2 - v_E| < 10^-15,
    |v_B2 - v_E| < 10^-15.                                        (4.1)

The class partition of HCSM-14 is blind to the distinction between the A_2,
B_2, and E isotypic sectors. This is a structural feature of the loop
operator's action on the multiplet. [ ]

Remark 4.1.1. The degeneracy of P_A2, P_B2, P_E coefficients reflects the
fact that the loop operator's class partition of HCSM-14 does not distinguish
these three sectors. The triple (A_2, B_2, E) shares the property of being
invisible to the winding generator's class structure.

4.2 No root generators
------------------------

Theorem 4.2 (No root generators). The loop commutant has zero overlap with
the root generators lambda^1, lambda^2, lambda^4, lambda^5, lambda^6,
lambda^7 of su(3)_c and sigma^1, sigma^2 of su(2)_L. Only the Cartan
generators lambda^3, lambda^8, sigma^3 of g_SM have nonzero overlap with the
loop commutant.

Proof. For each root generator g_j, project the unit coefficient vector
e_j in R^16 onto the nullspace N via the orthogonal projector P_N:

    ||P_N e_j|| < 10^-15,  j in {1, 2, 4, 5, 6, 7, 9, 10}.       (4.2)

The vanishing residuals reflect the fact that the loop operator breaks all
off-diagonal (root) directions of su(3)_c and su(2)_L. Only the diagonal
(Cartan) generators lambda^3, lambda^8, sigma^3 have nonzero overlap with
g_loop. [ ]

Corollary 4.3 (Loop commutant basis). The loop commutant g_loop is spanned
by three Hermitian combinations of {lambda^3, lambda^8, sigma^3, P_A1, P_A2,
P_B1, P_B2, P_E}, in which the coefficients on P_A2, P_B2, P_E are equal.

5. THE DNLS HARTREE HAMILTONIAN AND ITS COMMUTANT
================================================================================

5.1 Definition of H_DNLS on the 14-mode multiplet
---------------------------------------------------

Definition 5.1 (DNLS Hartree kernel). For each mode i of the 14-mode
multiplet, let phi_i(x, y) denote the normalized real wavefunction on the
torus (HCSM-04). The Hartree kernel is

    K_ab = sum_{x in Lambda} |phi_a(x)|^2 |phi_b(x)|^2,
    a, b = 1, ..., 14.                                            (5.1)

By HCSM-04, the diagonal of K equals the inverse participation ratio IPR_a,
taking values (2/128, 3/128, 4/128) on the three D_4 orbits.

Definition 5.2 (DNLS Hartree Hamiltonian). The DNLS Hartree Hamiltonian on
the 14-mode multiplet is

    H_DNLS = 4 I_14 + U K,                                        (5.2)

with U = B_mass = (d-1)kL^2/(2N^2) = 0.5411967342... the mass-map rate
(HCSM-19, HCSM-33).

H_DNLS is a real symmetric 14 x 14 matrix, hence Hermitian. It commutes with
no particular class projector in general, but as we prove below, it commutes
with the full su(2)_L factor of g_SM.

5.2 The DNLS commutant
------------------------

Definition 5.3 (DNLS commutant). The DNLS commutant is

    g_DNLS = g_SM cap Comm(H_DNLS).                               (5.3)

Theorem 5.4 (DNLS commutant dimension). The DNLS commutant g_DNLS is a
ten-dimensional real, Hermitian subalgebra of g_SM, isomorphic to
su(2)_L + u(1)^7.

Proof. The realified DNLS commutator matrix has rank 6 and nullity 10 at
machine precision, with a singular value gap of ~10^13 between the 6th and
7th singular values.

The nullspace decomposes explicitly as

    g_DNLS = su(2)_L + <P_A1, P_A2, P_B1, P_B2, P_E> + c,        (5.4)

where c is a two-dimensional abelian subalgebra of su(3)_c. Dimension count:
3 + 5 + 2 = 10.

The su(2)_L generators sigma^1, sigma^2, sigma^3 are non-abelian, with
structure constants [sigma^i, sigma^j] = i epsilon^{ijk} sigma^k matching
those of su(2). The two c generators are both Hermitian, traceless on the A_1
block, and commute with one another ([O_i, O_j] = 0 at machine precision);
they are therefore a 2-dimensional abelian subalgebra of su(3)_c. [ ]

6. EXACT PRESERVATION OF su(2)_L
================================================================================

6.1 The doubled-momentum pairing mechanism
--------------------------------------------

The exact preservation of su(2)_L is not generic; it is a consequence of a
precise pairing of mode momenta in the B_1 isotypic sector of the 14-mode
multiplet. We first state the structural lemma, then prove the main theorem.
The explicit construction of the B_1 basis vectors is given in Appendix A.

Lemma 6.1 (Doubled-momentum pairing). Let
U_B1 = [v_1^(B1), v_2^(B1)] in R^{14 x 2} be the explicit orthonormal basis
of the B_1 isotypic sector constructed in Appendix A. The two basis vectors
pair modes of the multiplet such that for each pair {m, m'} in the support of
v_1^(B1) and v_2^(B1), the doubled momenta agree:

    (2 n_1^(m), 2 n_2^(m)) = (2 n_1^(m'), 2 n_2^(m')) mod 8,      (6.1)

and the mode densities satisfy

    |phi_m(x)|^2 = |phi_{m'}(x)|^2,                               (6.2)

with the sign opposite between the two B_1 basis vectors.

Proof. See Appendix A. The B_1 isotypic sector is spanned by the
two-dimensional vector representation of D_4. The explicit basis vectors
constructed in Appendix A pair the modes as follows:

  - v_1 pairs nu = (0,4) and e = (4,0), both with doubled momentum
    (0,0) mod 8.
  - v_2 pairs u = (1,3) with dark = (5,7), tau = (7,5) with s = (3,1),
    d = (1,5) with b = (5,1), and c = (7,3) with mu = (3,7). In each pair,
    the two modes have the same doubled momentum.

Because K depends only on the squares |phi_a|^2 |phi_b|^2, the off-diagonal
entries of K_B1 are sums of terms with equal magnitudes and opposite signs.
[ ]

Theorem 6.2 (Doubled-momentum pairing theorem). The B_1-compressed Hartree
kernel vanishes identically:

    K_B1 = U_B1^T K U_B1 = 0 in R^{2 x 2}.                        (6.3)

Proof. The compression K_B1 has entries

    (K_B1)_ij = (v_i^(B1))^T K v_j^(B1)
              = sum_{a, b} v_i^(a) K_ab v_j^(b),  i, j in {1, 2}. (6.4)

Substituting K_ab = sum_x |phi_a(x)|^2 |phi_b(x)|^2:

    (K_B1)_ij = sum_x [sum_a v_i^(a) |phi_a(x)|^2]
                     [sum_b v_j^(b) |phi_b(x)|^2].                (6.5)

Define the two density profiles

    rho_i(x) = sum_a v_i^(a) |phi_a(x)|^2,  i = 1, 2.             (6.6)

Then (K_B1)_ij = sum_x rho_i(x) rho_j(x). We must show
sum_x rho_1(x) rho_2(x) = 0 and sum_x rho_1(x)^2 = sum_x rho_2(x)^2 = 0.

By Lemma 6.1, the two basis vectors v_1^(B1) and v_2^(B1) pair modes with
the same doubled momentum and opposite signs. For each pair {m, m'} in the
support, the contributions to rho_1(x) and rho_2(x) are

    rho_1(x) contains v_1^(m) |phi_m(x)|^2 + v_1^(m') |phi_{m'}(x)|^2
             = c_1 (|phi_m(x)|^2 - |phi_{m'}(x)|^2) = 0,          (6.7)

using |phi_m|^2 = |phi_{m'}|^2 from Lemma 6.1. Similarly rho_2(x) = 0.
Hence rho_1 = rho_2 = 0 identically, and K_B1 = 0. [ ]

Corollary 6.3 (su(2)_L preservation). The three generators sigma^1, sigma^2,
sigma^3 commute with the DNLS Hartree Hamiltonian:

    [sigma^i, K] = 0,  [sigma^i, H_DNLS] = 0,  i = 1, 2, 3.       (6.8)

Each of sigma^1, sigma^2, sigma^3 has overlap 1 with the DNLS commutant at
machine precision.

Proof. Since T_L^i = U_B1 sigma^i U_B1^T has support only on the B_1
isotypic sector, we have

    [T_L^i, K] = U_B1 [sigma^i, K_B1] U_B1^T
               + (terms acting on non-B_1 sectors that vanish by support).
                                                                   (6.9)

By Theorem 6.2, K_B1 = 0, so [sigma^i, K_B1] = 0 identically. Hence
[T_L^i, K] = 0 for all i. Since [sigma^i, I] = 0 trivially,
[T_L^i, H_DNLS] = 0. The overlap of sigma^i with the DNLS commutant
nullspace is thus 1 by direct computation. [ ]

Remark 6.4. The exact preservation is not an accident of the specific choice
of U_B1. It is a structural property of the B_1 isotypic sector's
doubled-momentum pairing. The mechanism is unique to su(2)_L; it does not
extend to su(3)_c, as proved in the next section.

7. BREAKING OF su(3)_c TO A TWO-DIMENSIONAL ABELIAN REMNANT
================================================================================

7.1 Root generator exclusion
------------------------------

Theorem 7.1 (su(3)_c breaking). The DNLS commutant contains a two-dimensional
abelian subalgebra c of su(3)_c. The root generators lambda^2, lambda^5,
lambda^7 have zero overlap with the DNLS commutant; the Cartan generators
lambda^3, lambda^8 have partial overlap.

Proof. Project each su(3)_c generator onto the DNLS nullspace N_DNLS in R^16
via the orthogonal projector P_{N_DNLS}. Direct computation gives

    ||P_{N_DNLS} e_j|| < 10^-10  for j in {2, 5, 7},              (7.1)

so lambda^2, lambda^5, lambda^7 are orthogonal to g_DNLS. The remaining five
su(3)_c generators lambda^1, lambda^3, lambda^4, lambda^6, lambda^8 have
partial overlap with N_DNLS; the two-dimensional abelian subalgebra c is a
specific Hermitian combination of these five generators that commutes with K.
Because c has dimension 2 and is abelian, it is a Cartan-like subalgebra of
su(3)_c. [ ]

Remark 7.1.1. The breaking pattern su(3)_c -> su(3)_c^Cartan (2-dimensional
abelian) is the color analog of the electroweak symmetry breaking pattern,
but it occurs at the substrate level (the mean-field Hartree dynamics) rather
than at the electroweak scale. It reflects the mismatch between the A_1
isotypic sector's mode-momentum pairing and the B_1 isotypic sector's
doubled-momentum pairing.

7.2 Dimension bookkeeping
---------------------------

The DNLS commutant dimension is 3 + 5 + 2 = 10, matching the theorem's
statement. The ten generators are:

  - sigma^1, sigma^2, sigma^3: full su(2)_L (3 generators, non-abelian).
  - P_A1, P_A2, P_B1, P_B2, P_E: full u(1)^5 (5 generators, abelian).
  - Two generators of the abelian subalgebra c in su(3)_c (2 generators,
    abelian).

Corollary 7.2 (Contrast with the loop commutant). The DNLS commutant
(10-dimensional, su(2)_L + u(1)^7) is strictly larger than the loop commutant
(3-dimensional, abelian). The two commutants share the u(1)^5 isotypic
projector sector but differ on the su(3)_c and su(2)_L content: the loop
operator preserves only the Cartan generators lambda^3, lambda^8, sigma^3
(three abelian directions), while the DNLS Hamiltonian preserves the full
su(2)_L factor and a two-dimensional abelian subalgebra of su(3)_c.

================================================================================
10. CONCLUSION
================================================================================

This paper has determined the gauge symmetry structure of the loop operator
and the DNLS Hartree Hamiltonian on the 14-mode multiplet of the Hodge
Complex Standard Model.

The loop operator M_loop = M_A P_A + M_B P_B + M_C P_C preserves a
three-dimensional real, Hermitian, abelian subalgebra of
g_SM = su(3)_c + su(2)_L + u(1)^5. The surviving generators are three
Hermitian combinations of the Cartan generators lambda^3, lambda^8, sigma^3
and the isotypic projectors, with equal coefficients on P_A2, P_B2, P_E. The
root generators lambda^{1,2,4,5,6,7} of su(3)_c and sigma^{1,2} of su(2)_L
are broken by the loop operator.

The DNLS Hartree Hamiltonian H_DNLS = 4I + UK preserves a larger
ten-dimensional subalgebra of g_SM, isomorphic to su(2)_L + u(1)^7. The full
su(2)_L factor is preserved exactly, a fact proved by a doubled-momentum
pairing mechanism: the two B_1 basis vectors pair modes with the same doubled
momentum (2n_1, 2n_2) mod 8 and opposite signs, forcing the B_1-compressed
kernel K_B1 = U_B1^T K U_B1 to vanish identically. The su(3)_c factor is
broken to a two-dimensional abelian subalgebra, with the root generators
lambda^2, lambda^5, lambda^7 orthogonal to the DNLS commutant.

The contrast between the two commutants (3-dimensional for the loop,
10-dimensional for the DNLS Hamiltonian) reflects the different symmetry
structures of the two operators. The loop operator is a class-partition
projector that selects only the abelian content of the multiplet; the DNLS
Hamiltonian is a mode-density kernel that preserves the full weak-isospin
structure through a doubled-momentum degeneracy specific to the B_1 isotypic
sector.

The exact su(2)_L preservation is the strongest structural statement in the
paper. It establishes that, at the mean-field level, the framework's
weak-interaction algebra is a robust symmetry of the substrate dynamics. The
su(3)_c breaking pattern is equally structural: it identifies precisely which
color directions survive the mean-field reduction, and it exhibits the
difference between the A_1 and B_1 isotypic sectors' pairing mechanisms.

APPENDIX A: EXPLICIT B_1 BASIS VECTORS AND THE DOUBLED-MOMENTUM PAIRING
            THEOREM
================================================================================

This appendix constructs the explicit orthonormal basis vectors of the B_1
isotypic sector of the 14-mode multiplet and verifies the doubled-momentum
pairing property used in Theorem 6.2.

A.1 The B_1 isotypic projector
--------------------------------

The B_1 isotypic projector on the 14-mode multiplet is

    P_B1 = (1/8) [ R(e) + R(r^2) - R(r) - R(r^3)
                 + R(s) + R(r^2 s) - R(rs) - R(r^3 s) ],          (A.1)

where the D_4 action on mode coordinates is given by (2.4). The B_1
character is chi_B1 = (1, 1, -1, 1, -1) on the conjugacy classes
(e, r^2, r, s, rs).

A.2 Explicit construction of the basis vectors
------------------------------------------------

Proposition A.1 (First B_1 basis vector). Applying P_B1 to the neutrino mode
nu = (0,4) gives, after normalization,

    v_1^(B1) = (|nu> - |e>) / sqrt(2)
             = (|(0,4)> - |(4,0)>) / sqrt(2).                     (A.2)

Proof. Direct computation:

    P_B1 |nu> = (1/8) [ |nu> + |nu> - |e> - |e>
                      + |nu> + |nu> - |e> - |e> ]
              = (1/8) [ 4|nu> - 4|e> ]
              = (|nu> - |e>) / 2.

Normalizing gives (A.2). [ ]

Proposition A.2 (Second B_1 basis vector). Applying P_B1 to the up-quark
mode u = (1,3) gives, after normalization,

    v_2^(B1) = (sqrt(2)/4) ( |u> + |tau> - |b> - |mu>
                           + |d> + |c> - |s> - |dark> ).          (A.3)

In coordinate form:

    v_2^(B1) = (sqrt(2)/4) ( |(1,3)> + |(7,5)> - |(5,1)> - |(3,7)>
                           + |(1,5)> + |(7,3)> - |(3,1)> - |(5,7)> ). (A.4)

Proof. Direct computation of P_B1 |u> gives

    P_B1 |u> = (1/8) [ |u> + |tau> - |b> - |mu>
                     + |d> + |c> - |s> - |dark> ].

The eight coefficients are +/- 1/8 in the standard mode order. Normalizing:
||P_B1 |u>||^2 = 8 * (1/8)^2 = 1/8, so the normalized vector is
sqrt(8) * P_B1 |u> = (sqrt(2)/4)(...). [ ]

Proposition A.3 (Orthonormality). The two vectors v_1^(B1) and v_2^(B1)
are orthonormal:

    v_1^(B1) . v_1^(B1) = 1,
    v_2^(B1) . v_2^(B1) = 1,
    v_1^(B1) . v_2^(B1) = 0.                                      (A.5)

Proof. For v_1: ||v_1||^2 = (1/2)(1 + 1) = 1. For v_2:
||v_2||^2 = (2/16) * 8 = 1. For the inner product: the supports of v_1 and
v_2 are disjoint (v_1 is supported on {nu, e} subset O_0, while v_2 is
supported on {u, d, s, mu, dark, c, tau, b} subset O_1), so the inner product
vanishes. [ ]

A.3 The matrix U_B1
---------------------

In the standard mode order (nu, e, u, d, s, mu, dark, c, tau, b, W, Z, H, t):

    U_B1 = [  1/sqrt(2)    0        ]
           [ -1/sqrt(2)    0        ]
           [  0            sqrt(2)/4]
           [  0            sqrt(2)/4]
           [  0           -sqrt(2)/4]
           [  0           -sqrt(2)/4]
           [  0           -sqrt(2)/4]
           [  0            sqrt(2)/4]
           [  0            sqrt(2)/4]
           [  0           -sqrt(2)/4]
           [  0            0        ]
           [  0            0        ]
           [  0            0        ]
           [  0            0        ]                               (A.6)

This matrix satisfies U_B1^T U_B1 = I_2.

A.4 Verification of the B_1 transformation properties
-------------------------------------------------------

Direct computation verifies that both basis vectors transform correctly under
the B_1 character chi_B1 = (1, 1, -1, 1, -1):

    g       | R(g) v_1  | R(g) v_2
    --------|-----------|-----------
    e       | +v_1      | +v_2
    r^2     | +v_1      | +v_2
    r       | -v_1      | -v_2
    r^3     | -v_1      | -v_2
    s       | +v_1      | +v_2
    r^2 s   | +v_1      | +v_2
    rs      | -v_1      | -v_2
    r^3 s   | -v_1      | -v_2

Both vectors transform as B_1. This confirms that U_B1 is a valid isotypic
basis.

A.5 The doubled-momentum pairing structure
--------------------------------------------

Proposition A.4 (Pairing structure of v_1). The vector v_1^(B1) pairs the
two modes nu = (0,4) and e = (4,0), both with doubled momentum

    (2*0, 2*4) = (2*4, 2*0) = (0, 0) mod 8,                       (A.7)

and with opposite signs +1/sqrt(2) and -1/sqrt(2).

Proposition A.5 (Pairing structure of v_2). The vector v_2^(B1) contains
four pairs of modes, each pair with the same doubled momentum and opposite
signs:

    Pair | Mode 1        | Double mom | Sign | Mode 2        | Double mom | Sign
    -----|---------------|------------|------|---------------|------------|-----
    1    | u = (1,3)     | (2,6)      | +    | dark = (5,7)  | (2,6)      | -
    2    | tau = (7,5)   | (6,2)      | +    | s = (3,1)     | (6,2)      | -
    3    | d = (1,5)     | (2,2)      | +    | b = (5,1)     | (2,2)      | -
    4    | c = (7,3)     | (6,6)      | +    | mu = (3,7)    | (6,6)      | -

Proof. Direct computation from (A.4). For pair 1: u = (1,3) has doubled
momentum (2,6); dark = (5,7) has doubled momentum (10, 14) = (2, 6) mod 8.
The coefficients in v_2 are +sqrt(2)/4 and -sqrt(2)/4 respectively. The other
three pairs are verified analogously. [ ]

A.6 Proof that K_B1 = 0
--------------------------

Theorem A.6 (B_1-compressed kernel vanishes). The B_1-compressed Hartree
kernel vanishes identically:

    K_B1 = U_B1^T K U_B1 = 0 in R^{2 x 2}.                        (A.8)

Proof. The compression K_B1 has entries

    (K_B1)_ij = (v_i^(B1))^T K v_j^(B1) = sum_x rho_i(x) rho_j(x), (A.9)

where the density profiles are

    rho_i(x) = sum_a v_i^(a) |phi_a(x)|^2,  i = 1, 2.             (A.10)

For i = 1: using Proposition A.4,

    rho_1(x) = (1/sqrt(2)) ( |phi_nu(x)|^2 - |phi_e(x)|^2 ).      (A.11)

Since nu = (0,4) and e = (4,0) are both in O_0, we have
|phi_nu(x)|^2 = |phi_e(x)|^2 = 1/64 for all x in Lambda. Therefore
rho_1(x) = 0 for all x in Lambda.

For i = 2: using Proposition A.5,

    rho_2(x) = (sqrt(2)/4) [ |phi_u(x)|^2 - |phi_dark(x)|^2
                           + |phi_tau(x)|^2 - |phi_s(x)|^2
                           + |phi_d(x)|^2 - |phi_b(x)|^2
                           + |phi_c(x)|^2 - |phi_mu(x)|^2 ].     (A.12)

For each of the four pairs, the two modes have equal density:

    |phi_u(x)|^2 = |phi_dark(x)|^2  (by the doubled-momentum pairing)
    |phi_tau(x)|^2 = |phi_s(x)|^2
    |phi_d(x)|^2 = |phi_b(x)|^2
    |phi_c(x)|^2 = |phi_mu(x)|^2

Therefore each bracket vanishes identically, and rho_2(x) = 0 for all x in
Lambda.

Since rho_1 = rho_2 = 0 identically, every entry of K_B1 vanishes:

    K_B1 = [ 0  0 ]
           [ 0  0 ].                                               (A.13)
[ ]

A.7 Corollary: exact su(2)_L preservation
-------------------------------------------

Corollary A.7 (su(2)_L preservation on the 14-mode multiplet). The three
generators of su(2)_L commute with the Hartree kernel and the DNLS
Hamiltonian:

    [T_L^i, K] = 0,  [T_L^i, H_DNLS] = 0,  i = 1, 2, 3.           (A.14)

Proof. Since T_L^i = U_B1 sigma^i U_B1^T has support only on the B_1
isotypic sector:

    [T_L^i, K] = U_B1 [sigma^i, K_B1] U_B1^T
               + (terms on non-B_1 sectors that vanish by support).

By Theorem A.6, K_B1 = 0, so [sigma^i, K_B1] = 0 identically. Hence
[T_L^i, K] = 0 for all i. Since [sigma^i, I] = 0 trivially,
[T_L^i, H_DNLS] = 0. [ ]

square lattice — forces the entire Hodge Complex Standard Model (HCSM)
substrate, including the periodic 8 x 8 torus Λ = Z_8 x Z_8, the 14-mode

and the four-mode set {u, s, dark, τ} carries a faithful Klein four-

single lattice primitive via the entropy-spacing selection of L = 8.
The physical reading of 7/32 — the identification of the surviving 14
modes with the residual dark-energy density ρ_DE = (d+1)/2 · m_ν^4
matching observation to 0.010% — is derived in the companion paper
HCSM-53. Every numerical claim is verified in IEEE-754 double precision
and is exact in rational arithmetic.

2.1 The lattice

By the lattice primitive, the substrate is Λ_L = Z_L x Z_L with L even.
Site (x_1, x_2) is identified with (x_1 + L, x_2) and with (x_1, x_2 + L).
The lattice carries the D_4 point group of the square, generated by

    r : (n_1, n_2) |-> (-n_2, n_1)  mod L
    s : (n_1, n_2) |-> (n_1, -n_2)  mod L

with presentation r^4 = s^2 = (rs)^2 = e.

2.2 The 5-point Laplacian

THEOREM 2.1 (Laplacian uniqueness). Let Δ be a linear operator on Λ_L
satisfying:

    (i)   D_4-invariance: [R, Δ] = 0 for every R ∈ D_4;
    (ii)  nearest-neighbour locality: (Δf)(x) depends only on f(x) and
          f at the four nearest neighbours of x;
    (iii) positivity and kernel: Δ is positive-semidefinite and ker Δ
          is exactly the set of constant functions.

Then Δ is uniquely determined up to an overall positive scale, and
equals the 5-point Laplacian

    (Δf)(x_1, x_2) = 4 f(x_1, x_2)
                   - f(x_1+1, x_2) - f(x_1-1, x_2)
                   - f(x_1, x_2+1) - f(x_1, x_2-1).    (2.1)

Proof. Condition (ii) writes Δf(x) = a_0 f(x) + Σ_μ a_μ f(x + μ) over
the four nearest-neighbour vectors μ ∈ {±e_1, ±e_2}. These four
directions form a single D_4 orbit, so condition (i) forces a_μ = a
for all four. Condition (iii) forces Δ 1 = 0, hence a_0 + 4a = 0 or
a_0 = -4a. Normalizing a = 1 gives (2.1).  []

2.3 The Laplacian spectrum

For (n_1, n_2) ∈ {0, ..., L-1}^2, define the plane wave

    φ_{n_1, n_2}(x_1, x_2) = exp( 2πi (n_1 x_1 + n_2 x_2) / L ).   (2.2)

Direct application of (2.1) gives the eigenvalue

    λ(n_1, n_2) = 4 - 2 cos( 2π n_1 / L ) - 2 cos( 2π n_2 / L ).   (2.3)

COROLLARY 2.2. λ(n_1, n_2) ∈ [0, 8], with minimum 0 attained only at
(0, 0) and maximum 8 attained only at (L/2, L/2).

3. MIRROR SYMMETRY
--------------------------------------------------------------------------------

DEFINITION 3.1 (Half-period translation). The half-period translation
is the map

    T_half(n_1, n_2) = ( (n_1 + L/2) mod L, (n_2 + L/2) mod L ).

LEMMA 3.2. T_half is an involution on {0, ..., L-1}^2.

Proof. (n + L/2 + L/2) mod L = n mod L for both coordinates.  []

LEMMA 3.3 (Cosine shift). For n ∈ {0, ..., L-1} with L even,

    cos( 2π · ((n + L/2) mod L) / L ) = -cos( 2π n / L ).

Proof. Let m = (n + L/2) mod L. If n < L/2, then m = n + L/2 and
cos(2π m / L) = cos(2π n / L + π) = -cos(2π n / L). If n ≥ L/2, then
m = n - L/2 and cos(2π m / L) = cos(2π n / L - π) = -cos(2π n / L).
Both cases coincide.  []

THEOREM 3.4 (Mirror symmetry). For every momentum pair (n_1, n_2),

    λ( T_half(n_1, n_2) ) = 8 - λ(n_1, n_2).

Consequently, the spectrum of Δ on Λ_L is exactly mirror-symmetric:
if λ is an eigenvalue with multiplicity m, then 8 - λ is also an
eigenvalue with multiplicity m.

Proof. By (2.3), λ(n_1, n_2) = 4 - 2 cos(2π n_1 / L) - 2 cos(2π n_2 / L).
Applying T_half to both coordinates and using Lemma 3.3:

    λ( T_half(n_1, n_2) ) = 4 - 2 (-cos(2π n_1 / L)) - 2 (-cos(2π n_2 / L))
                          = 4 + 2 cos(2π n_1 / L) + 2 cos(2π n_2 / L)
                          = 8 - λ(n_1, n_2).

T_half is a bijection by Lemma 3.2, so it pairs eigenvalues λ and
8 - λ at equal multiplicity.  []

COROLLARY 3.5. Every eigenvalue λ ≠ 4 appears in a mirror pair
(λ, 8 - λ) of equal multiplicity.

4. THE SELF-PAIRED EIGENVALUE
--------------------------------------------------------------------------------

DEFINITION 4.1. An eigenvalue λ is self-paired if λ = 8 - λ.

THEOREM 4.2. The unique self-paired eigenvalue is λ = 4.

Proof. λ = 8 - λ implies 2λ = 8, hence λ = 4.  []

THEOREM 4.3 (Multiplicity at λ = 4). For every even L, the multiplicity
of λ = 4 is

    mult_{λ=4}(Λ_L) = 2(L - 1).

Proof. The λ = 4 eigenspace is the set of (n_1, n_2) satisfying

    cos(2π n_1 / L) + cos(2π n_2 / L) = 0.

Using the sum-to-product identity cos a + cos b = 2 cos((a+b)/2)
cos((a-b)/2), this becomes

    2 cos( π(n_1+n_2) / L ) cos( π(n_1-n_2) / L ) = 0.

So either n_1 + n_2 ≡ L/2 mod L or n_1 - n_2 ≡ L/2 mod L. Each
congruence has L solutions in Z_L x Z_L. Their intersection is the
set of (n_1, n_2) satisfying both, which gives n_1 = n_2 + L/2 and
n_1 + n_2 = L/2 simultaneously, i.e., 2n_1 = L and 2n_2 = 0 modulo L.
The intersection has exactly two points: (0, L/2) and (L/2, 0). By
inclusion-exclusion,

    mult_{λ=4} = L + L - 2 = 2(L - 1).  []

REMARK 4.4. At L = 8, Theorem 4.3 gives mult_{λ=4} = 14. This is
the central 14-mode multiplet of HCSM [HCSM-04].

6. THE CANCELLATION THEOREM
--------------------------------------------------------------------------------

THEOREM 6.1 (General cancellation). Let F : R -> R satisfy

    F(λ) + F(8-λ) = c

for all λ and some constant c ∈ R. Then

    Σ_m F(λ_m) = c · (L^2 - 2(L-1))/2  +  F(4) · 2(L-1).

Proof. Group the L^2 modes into (L^2 - 2(L-1)) paired modes and
2(L-1) residual modes at λ = 4. Each pair (λ, 8 - λ) with multiplicity
m_p contributes m_p · c by hypothesis. Summing over all pairs gives
c · (L^2 - 2(L-1))/2. Adding the residual contribution 2(L-1) · F(4)
gives the result.  []

COROLLARY 6.2 (L = 8). At L = 8,

    Σ_m F(λ_m) = 25 c + 14 F(4).

Proof. Substitute L = 8: (64 - 14)/2 = 25, 2 · 7 = 14.  []

7. THE RESIDUAL RATIO 7/32
--------------------------------------------------------------------------------

THEOREM 7.1. For the zero-point convention F(λ) = λ/2 and L = 8:

    Σ_m F(λ_m) = 128,
    Σ_{m ∈ R} F(λ_m) = 28,
    Σ_{m ∈ R} F(λ_m) / Σ_m F(λ_m) = 7/32,

where R is the residual set of 14 modes at λ = 4.

Proof. Compute Σ_m λ_m exactly. Using the trigonometric identity

    Σ_{n=0}^{7} cos(π n / 4) = 0,

we have

    Σ_m λ_m = Σ_{n_1, n_2 = 0}^{7} [ 4 - 2 cos(π n_1 / 4) - 2 cos(π n_2 / 4) ]
            = 4 · 64 - 2 · 8 · Σ_{n=0}^{7} cos(π n / 4)
                    - 2 · 8 · Σ_{n=0}^{7} cos(π n / 4)
            = 256 - 0 - 0 = 256.

Therefore Σ_m λ_m/2 = 128.

The residual contribution is Σ_{m ∈ R} λ_m/2 = 14 · (4/2) = 28.

Ratio: 28/128 = 7/32.  []

COROLLARY 7.2 (Explicit split). Σ_paired F(λ_m) = 100 and
Σ_R F(λ_m) = 28. The paired modes contribute 25/32 of the total; the
residual contributes 7/32.

8. CONVENTION INDEPENDENCE
--------------------------------------------------------------------------------

THEOREM 8.1. Let F(λ) = α λ + β with α > 0 and F(4) ≠ 0. Then

    Σ_{m ∈ R} F(λ_m) / Σ_m F(λ_m) = 7/32.

If F(4) = 0 (equivalently β = -4α), both numerator and denominator
vanish, and the ratio is undefined.

Proof. Compute:

    Σ_{m ∈ R} F(λ_m) = 14 F(4) = 14 (4α + β).
    Σ_m F(λ_m) = α Σ_m λ_m + 64 β = 256α + 64β = 64 (4α + β).

Ratio = 14 (4α + β) / [64 (4α + β)] = 14/64 = 7/32, provided
4α + β ≠ 0. If 4α + β = 0, then F(4) = 0 and both sums vanish; the
ratio is undefined.  []

REMARK 8.2 (Correction note). An earlier revision claimed the ratio
7/32 holds for β = -4α. That is exactly the degenerate case. The
correct statement is the opposite: the ratio holds for any affine F
EXCEPT the degenerate case β = -4α.

COROLLARY 8.3 (Geometric content). The convention-independent content
of the cancellation is

    Σ_{m ∈ R} λ_m / Σ_m λ_m = 56 / 256 = 7/32.

The numerator 14 · 4 = 56 is multiplicity times the midpoint
eigenvalue; the denominator 64 · 4 = 256 is total mode count times the
midpoint eigenvalue.

9. THE TF OPERATOR AND THE |Δn| GRADING
--------------------------------------------------------------------------------

DEFINITION 9.1 (Diagonal flip). The diagonal flip is
F : (n_1, n_2) |-> (n_2, n_1) on Λ_L.

DEFINITION 9.2 (TF operator). The TF operator is the composition

    TF := T_half ∘ F,
    TF(n_1, n_2) = ( (n_2 + L/2) mod L, (n_1 + L/2) mod L ).

LEMMA 9.3. TF^2 = id.

Proof. TF^2(n_1, n_2) = TF(n_2 + L/2, n_1 + L/2) = (n_1 + L, n_2 + L)
= (n_1, n_2) mod L.  []

THEOREM 9.4 (TF grading by |Δn|). Let Δn := n_2 - n_1 on Λ_8. On
the 14 modes at λ = 4:

    TF-fixed modes:  all modes with Δn ≡ 4 mod 8. There are 8 such
                     modes: {ν, e, d, b, μ, c, Z, H}.

    TF 2-cycle modes: all modes with Δn ≢ 4 mod 8. There are 6 such
                      modes, forming three 2-cycles: {u, τ},
                      {s, dark}, {W, t}.

Proof. TF-fixed iff (n_2 + 4) mod 8 = n_1 and (n_1 + 4) mod 8 = n_2,
equivalent to n_2 - n_1 ≡ 4 mod 8. By the parity constraint
n_1 ≡ n_2 mod 2 (which holds on every mode at λ = 4), the condition
Δn ≡ 4 mod 8 is equivalent to |Δn| = 4. Direct enumeration of the 14
modes confirms:

    8 modes with |Δn| = 4: {ν, e, d, b, μ, c, Z, H};
    4 modes with |Δn| = 2: {u, s, dark, τ};
    2 modes with |Δn| = 0: {W, t}.

Direct check of the 2-cycles confirms: TF(u) = τ, TF(s) = dark,
TF(W) = t.  []

COROLLARY 9.5 (TF-fixed <=> higher N/4). On each T_half pair, the
TF-fixed member is exactly the member with smaller n_1, which by the
HCSM-23 within-pair ordering rule receives the higher N/4 label.

Proof. Let {m, m'} be a T_half pair with n_1(m) < n_1(m'). Then
TF(m) = T_half(F(m)) = T_half(m') = m by direct computation (since
T_half is the involution pairing m with m' and F(m) = m' for modes
in the same T_half pair). Hence the smaller-n_1 member is TF-fixed.
Since HCSM-23 assigns the higher N/4 to the smaller-n_1 member,
TF-fixed <=> higher N/4.  []

REMARK 9.6. Corollary 9.5 DERIVES the HCSM-23 within-pair ordering
rule from the TF operator of the substrate. What was stated as a rule
in HCSM-23 is now a theorem of the single lattice primitive.

10. KLEIN FOUR-ORBIT STRUCTURE
--------------------------------------------------------------------------------

DEFINITION 10.1 (Substrate involutions). On Λ_8, three commuting
involutions act on the mode labels:

    F         : (n_1, n_2) |-> (n_2, n_1),
    TF        : (n_1, n_2) |-> ((n_2 + 4) mod 8, (n_1 + 4) mod 8),
    F · TF    : (n_1, n_2) |-> ((n_1 + 4) mod 8, (n_2 + 4) mod 8).

All three commute pairwise.

THEOREM 10.2 (Klein four-orbit). The four modes {u, s, dark, τ} carry
a faithful action of the Klein four-group V_4 = {id, F, TF, F · TF}:

    F       : u <-> s,     dark <-> τ,
    TF      : u <-> τ,     s <-> dark,
    F · TF  : u <-> dark,  s <-> τ.

The action is faithful, transitive, and free (no stabilizer).

Proof. Direct computation on the four modes. All three involutions
act as products of two disjoint transpositions, pairwise commute, and
generate the Klein four-group. No mode is fixed by any non-identity
element, so the action is free.  []

COROLLARY 10.3. The Klein four-orbit {u, s, dark, τ} is generated by
the substrate involutions F and TF. This is the HCSM-27 Klein orbit,
now derived from the single lattice primitive.

THEOREM 11.1 (Entropy spacing selects L = 8). Among all integers
4 ≤ L ≤ 10^4, the only L for which the L x L torus has exactly three
equally spaced Shannon entropy classes is L = 8. At L = 8 the three
classes are 6.0 bits, 5.5 bits, and 5.0 bits, with uniform spacing
0.5 bits.

Proof sketch. Compute the Shannon entropy

    S(n_1, n_2) = -Σ_x |φ_{n_1, n_2}(x)|^2 log_2 |φ_{n_1, n_2}(x)|^2

of each mode. For each even L, count the number of distinct entropy
classes and their spacing. A direct enumeration over L ∈ [4, 10^4]
gives the stated uniqueness. The full computation is reproduced in
HCSM-01 and verified at machine precision.  []

The two selections use different aspects of the substrate (entropy

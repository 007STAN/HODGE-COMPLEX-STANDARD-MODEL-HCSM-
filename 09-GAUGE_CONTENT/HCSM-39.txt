1.1 The Weinberg angle in the Standard Model
--------------------------------------------------------------------------------

The weak mixing angle theta_W, or equivalently sin^2 theta_W, is one of the
fundamental parameters of the Standard Model. Its value at the Z-pole is
measured to be

    sin^2 theta_W(M_Z) = 0.23122 +/- 0.00004,

using the MS-bar scheme. In the Standard Model, this value is a free
parameter; it is not derived from any deeper principle. The theory inputs
sin^2 theta_W as a boundary condition and runs the gauge couplings between
observed scales.

In grand unified theories (GUTs), the weak mixing angle acquires a
theoretical significance. If the three gauge couplings g_1, g_2, g_3 unify
at some high scale M_GUT, the boundary condition

    sin^2 theta_W(M_GUT) = 3/8

is a theorem of the SU(5) embedding. Running this value down to M_Z with only
the Standard Model content gives sin^2 theta_W(M_Z) ~ 0.1884, off by 19% from
observation. The discrepancy is the classic GUT failure: the SM does not
unify in the minimal SU(5) framework.

Extensions of the Standard Model (supersymmetric, extra-dimensional, or
hidden-sector) modify the beta-function coefficients and can restore
agreement. In this paper we show that the Hodge Complex Standard Model
provides the exact hidden sector content needed to reconcile the GUT-scale
boundary condition with the observed value at M_Z, with no free parameters.

3. BETA-FUNCTION COEFFICIENTS OF THE HIDDEN SECTOR
================================================================================

--------------------------------------------------------------------------------
3.1 The running equation
--------------------------------------------------------------------------------

For a gauge group G with coupling g, the one-loop beta-function coefficient is

    b_G = (11/3) C_2(G) - (2/3) sum_{Weyl} T(R) - (1/6) sum_{scalar} T(R),

where C_2(G) is the quadratic Casimir of the adjoint representation, and
T(R) is the Dynkin index of representation R, normalized to
T(fundamental of SU(N)) = 1/2. For the Standard Model gauge groups:

    C_2(SU(3)) = 3, C_2(SU(2)) = 2, C_2(U(1)_Y) = 0.

--------------------------------------------------------------------------------
3.2 Standard Model contributions
--------------------------------------------------------------------------------

For the Standard Model with one Higgs doublet, the beta-function coefficients
are

    b_1^SM = 41/10 = 4.100,
    b_2^SM = -19/6 = -3.167,
    b_3^SM = -7.

These include contributions from quarks, leptons, the Higgs, and the gauge
bosons.

--------------------------------------------------------------------------------
3.3 Hidden sector contributions
--------------------------------------------------------------------------------

We consider two scenarios for the hypercharge of the hidden states.

SCENARIO A: HIDDEN STATES CARRY HYPERCHARGE. If the hypercharge functional
extends to the hidden sector with the same coefficients as in the gauge paper
(HCSM-06), the hidden B1 states carry Y = -1/2 (from Omega^1) and Y = 0
(from Omega^2), and the hidden A1 states carry Y = +1/6 (from Omega^1) and
Y = +1/3 (from Omega^2). Direct computation gives

    b_1^hid,A = 11/10 = 1.100,
    b_2^hid,A = 5/3 = 1.667,
    b_3^hid,A = 2.

This scenario is excluded by observation (see Section 5).

SCENARIO B: HIDDEN STATES ARE U(1)_Y-NEUTRAL. If the U(1)_Y functional is
defined only on the visible sector, hidden states have Y = 0. The
beta-function contributions are then:

    b_1^hid,B = 0,
    b_2^hid,B = 5 * (2/3) * (1/2) = 5/3 = 1.667,
    b_3^hid,B = 6 * (2/3) * (1/2) = 2.

Here we have used:

    - The factor 5 (or 6) counts the number of hidden doublets (or triplets).
    - The factor 2/3 is the fermionic statistics factor.
    - The factor 1/2 is the Dynkin index T(fundamental) for su(2)_L (or
      su(3)_c).

THEOREM 3.1 (Hidden sector beta-function coefficients). Under Disclosed
Choices 1 and 2 (fermionic, U(1)_Y-neutral hidden B1 doublets), the hidden
sector contributes to the one-loop beta-function coefficients:

    b_1^hid = 0, b_2^hid = 5/3, b_3^hid = 2.

Proof. Direct computation from the hidden sector content of Table 1 and the
beta-function formula. See Section 3.3.

REMARK 3.1. The critical feature of Scenario B is b_1^hid = 0. The running
of alpha_1 (the hypercharge coupling) is unchanged by the hidden sector,
while alpha_2 and alpha_3 run more slowly because of the additional doublets
and triplets. This asymmetry is what distinguishes Scenario B from
Scenario A in the running to M_Z.

4. RGE RUNNING FROM M_GUT TO M_Z
================================================================================

--------------------------------------------------------------------------------
4.1 Boundary condition and inputs
--------------------------------------------------------------------------------

We impose the standard GUT-scale boundary condition

    sin^2 theta_W(M_GUT) = 3/8,

equivalently alpha_1(M_GUT) = alpha_2(M_GUT). The numerical inputs are

    M_GUT = 2e16 GeV,
    L = ln(M_GUT/M_Z) = 33.02,

    alpha_em^{-1}(M_Z) = 127.9 (input).

--------------------------------------------------------------------------------
4.2 Running equations
--------------------------------------------------------------------------------

At one loop, the gauge couplings run as

    d alpha_i^{-1} / d ln mu = -b_i / (2 pi),

so that

    alpha_i^{-1}(M_Z) = alpha_i^{-1}(M_GUT) + b_i L / (2 pi).

Since alpha_1(M_GUT) = alpha_2(M_GUT) = alpha_GUT, and using the SM relation

    alpha_em^{-1} = (5/3) alpha_1^{-1} + alpha_2^{-1},

we obtain the running of the electromagnetic coupling:

    alpha_em^{-1}(M_Z) = (8/3) alpha_GUT^{-1}
                       + ((5/3) b_1 + b_2) L / (2 pi).

Solving for alpha_GUT^{-1}:

    alpha_GUT^{-1} = (3/8) [alpha_em^{-1}(M_Z) - b_em L / (2 pi)],

with b_em = (5/3) b_1 + b_2.

The gauge couplings at M_Z are

    alpha_1^{-1}(M_Z) = alpha_GUT^{-1} + b_1 L / (2 pi),
    alpha_2^{-1}(M_Z) = alpha_GUT^{-1} + b_2 L / (2 pi).

The weak mixing angle is

    sin^2 theta_W(M_Z) = alpha_2^{-1}(M_Z) / alpha_em^{-1}(M_Z).

--------------------------------------------------------------------------------
4.3 Numerical evaluation
--------------------------------------------------------------------------------

We evaluate the running for three scenarios: (i) the Standard Model alone;
(ii) the framework with hidden states carrying hypercharge (Scenario A);
(iii) the framework with U(1)_Y-neutral hidden states (Scenario B).

STANDARD MODEL ALONE. With b_1^SM = 4.100, b_2^SM = -3.167:

    b_em^SM = (5/3) * 4.100 + (-3.167) = 6.833 - 3.167 = 3.666,
    alpha_GUT^{-1} = (3/8) [127.9 - (3.666/(2 pi)) * 33.02]
                   = (3/8) * 108.6 = 40.74,
    alpha_2^{-1}(M_Z) = 40.74 + (-3.167) * 33.02 / (2 pi)
                      = 40.74 - 16.64 = 24.10,
    sin^2 theta_W(M_Z)_SM = 24.10 / 127.9 = 0.1884.

This is off from observation by 19%.

FRAMEWORK, SCENARIO A. With b_1 = 4.100 + 1.100 = 5.200,
b_2 = -3.167 + 1.667 = -1.500:

    b_em^A = (5/3) * 5.200 + (-1.500) = 8.667 - 1.500 = 7.167,
    alpha_GUT^{-1} = (3/8) [127.9 - (7.167/(2 pi)) * 33.02]
                   = (3/8) * 90.1 = 33.79,
    alpha_2^{-1}(M_Z) = 33.79 + (-1.500) * 33.02 / (2 pi)
                      = 33.79 - 7.88 = 25.91,
    sin^2 theta_W(M_Z)_A = 25.91 / 127.9 = 0.2026.

This is off from observation by 12%. Scenario A is excluded.

FRAMEWORK, SCENARIO B. With b_1 = 4.100 + 0 = 4.100,
b_2 = -3.167 + 1.667 = -1.500:

    b_em^B = (5/3) * 4.100 + (-1.500) = 6.833 - 1.500 = 5.333,
    alpha_GUT^{-1} = (3/8) [127.9 - (5.333/(2 pi)) * 33.02]
                   = (3/8) * 99.9 = 37.46,
    alpha_2^{-1}(M_Z) = 37.46 + (-1.500) * 33.02 / (2 pi)
                      = 37.46 - 7.88 = 29.58,
    sin^2 theta_W(M_Z)_B = 29.58 / 127.9 = 0.2312.

This matches observation 0.23122 to 0.02%.
